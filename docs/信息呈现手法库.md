# 信息呈现手法库

把「一句话要讲的信息」变成「一个会动的画面」的套路。每条写：什么时候用 → 参考片怎么做 → 我们怎么做得更好 → 用工具包里的哪个件。
✅ = 工具包已有可直接用；🔧 = 有近似件要改一改；🔨 = 还没有，第一次用到时做出来并沉淀进工具包。

做分镜时的用法：拿到一句文案，先问「这句话的信息是哪一类」，再从下面挑一种呈现方式。同一种手法一期里别连用超过 2 次。

---

## A. 数字类

| 手法 | 什么时候用 | 参考片 | 我们更好的做法 | 工具包 |
|---|---|---|---|---|
| **数字卡 + 滚动计数** | 一个让人吃惊的大数（60 万亿美元、2000 万册） | 静态金框数字（《人类简史》1:21「60 万亿」） | 数字从 0 滚到目标、最后一位落定时一个 `big_ding` + 轻震屏；单位后弹出 | ✅ `ui.hud_popup` `gameui.result_panel(count)` `anim.counter` · 声 `digit_ticks` `result_ding` |
| **比例可视化** | 「超过九成」「三十二分之一」 | 大字「51%」/「1/32」 | 用实物堆：100 个小方块里 91 个变灰（一眼看出比例），或者金币塔只剩顶上一小格亮 | 🔨 `ratio_grid(n, k)` |
| **前后对比计时器** | 同一指标随时间变化（专注 2:30 → 1:15 → 0:47） | 三个并排面板逐个出现（《深度工作》0:30–0:36） | 同一个计时器在同一位置「缩水」：指针回拨 + 数字滚动 + 每一档一个年份标签换上来，变化本身成为画面 | 🔧 `ui.hud_time` + `anim.counter` |
| **进度 / 计数条** | 房贷 15/360 期、第 N 天 | 右上角红色计数（《人类简史》0:21） | 计数和角色动作绑定（每爬一级楼梯 +1 期），计数跳动带 1 px 抖动 | ✅ `ui.hud_counter` `gameui.task_tracker` |
| **复利 / 翻倍** | 指数增长（一分钱翻倍 30 天） | 日历格子里金币柱逐格变高（《滚雪球》0:48） | 同样逐格长，但镜头跟着最高那根往上摇，最后一天柱子冲出画面顶 → 拉远揭示 | 🔨 `growth_calendar` |

## B. 人物 / 书 / 机构

| 手法 | 什么时候用 | 参考片 | 我们更好的做法 | 工具包 |
|---|---|---|---|---|
| **RPG 人物卡** | 第一次介绍作者、名人 | 金框卡：头像 + 名字 + 头衔 + 2–3 行属性（《深度工作》纽波特、盖茨，《富爸爸》「拳王 Lv99」） | 头像必须是**同一画风的像素角色**（不用照片转像素）；卡片属性行逐行打字揭示，最后一行是笑点（「会议：0」） | ✅ `gameui.char_card` `ui.name_card` · 声 `ui_slide` `typing` |
| **书本登场** | 每期第一次出现这本书 | 书封悬浮发光 + 光柱（《富爸爸》0:15） | 书从角色手里 / 书架上被抽出来（有动机），翻开 = 进入正文的转场 | 🔨 `book_prop(open_k)` |
| **权威背书** | 销量、推荐人 | 推荐徽章一个个盖上（《人类简史》0:45） | 徽章「盖章」式砸下来，每个一声 `stamp`，最后一个让书弹一下 | ✅ `ui.rubber_stamp` `ui.stamp_sprite` |
| **主持人锚点** | 段落之间回到「讲述者」 | 固定律师事务所主持人画面反复出现 | 主持人每次回来**换一个小状态**（喝茶 / 翻书 / 指黑板），不是同一张图；黑板内容和本段相关 | 🔨 每期一个 host set |

## C. 概念 / 抽象

| 手法 | 什么时候用 | 参考片 | 我们更好的做法 | 工具包 |
|---|---|---|---|---|
| **一个贯穿全片的隐喻** | 每期必用：把书的核心观点变成一个可以「玩」的东西 | 故事→书页、老鼠赛跑→仓鼠轮、雪球→雪景球、复利→武器 | 隐喻要能**变化**（仓鼠轮越转越快、雪球越滚越大），并在结尾回收 | 每期新做 |
| **标签贴物** | 「这张纸 / 这个头像」——指出画面里的东西叫什么 | 白底小标签弹在物体旁（《人类简史》0:10「头像」「纸」） | 标签带引线、从物体上「长」出来；被说到的那一刻物体描边高亮 1 次 | ✅ `ui.tooltip` `ui.highlight` |
| **反问三连** | 「是车吗？是工厂吗？是员工吗？」 | 每问换一个画面，标志悬浮在上方（《人类简史》2:21–2:39） | 每问一个画面 + 一个「✗」盖上去，第三次翻转（东西都被拿走了，标志还在），节奏越来越快 | ✅ `gameui.choice_panel` `ui.stamp_sprite` · 声 `deny` |
| **游戏界面隐喻** | 「你不用退出这个游戏」 | 暂停菜单「继续游戏 / 退出游戏✗」（《人类简史》4:51） | 光标真的移上去 → 点「退出」→ 按钮被锁住抖动 → 光标移回「继续」 | ✅ `gameui.choice_panel` `ui.cursor` `gameui.game_button` |
| **背包 / 分类** | 「哪些是故事、哪些是真的」 | 背包两栏格子（《人类简史》4:54） | 道具一个个飞进对应格子，飞对一个 `ok` | ✅ `gameui.item_row` `gameui.item_card` |
| **兑换券 / 任务奖励** | 给方法、清单 | 「赎回券 壹 / 贰 / 叁」逐张翻开（《深度工作》2:12） | 每张券兑换时有「撕下」动作 + 盖「已兑换」章 + 进度 1/3 → 2/3 | ✅ `gameui.item_card` `ui.rubber_stamp` `ui.quest_list` |
| **等式 / 公式** | 「产出 = 时间 × 专注度」 | 三格并排（《深度工作》1:36） | 公式的每一项是画面里的真实物件，乘号出现时两件东西「合体」 | 🔨 `formula_row` |

## G. 特效（pixelfx，244 个，见 `工具包/vendor/pixelfx/docs/CATALOG.md`）

**定位：调味料，不是主菜。** 实测合成进 pixelkit 画面（`_work/pfx_eval/`）：像素网格完全吻合、光和颜色质量高，但它是「游戏战斗特效库」，
244 个里对知识视频真正有用的约 60–80 个。

| 用 | 类别 | 用在知识视频的哪里 |
|---|---|---|
| ★★★ | `transitions/`（10 个，320×180 全屏） | 段落转场：iris / star-iris（收束到一个点再打开）、pixel-dissolve、blinds、crt-off（关机 = 结束一段）、glitch-wipe（「系统出错」类反转）。**这是 pixelkit 最缺的一块**（原来只有溶解 / 甩镜 / 推进屏幕 / 融化） |
| ★★★ | `ui/` `pickups/` | 数据爆点（crit-number 的星爆）、获得方法（chest-open、key-glint、collect-burst）、计数（coin-collect、combo-counter）、倒计时 countdown、完成 quest-complete / level-up |
| ★★ | `impacts/` | 重读词的冲击：hit-spark、blunt-hit；`impact-frame`（2 帧黑白放射线）= 金句砸下那一下 |
| ★★ | `fire/` `water/` `weather/` `critters/` | 场景氛围：烛光、篝火、雨、雪、落叶、樱花、鸟群、蝴蝶、鱼群 |
| ★ | `explosions/`（cartoon-pow、firework）`spawn/`（poof、coin-drop） | 喜剧爆点、东西「消失 / 出现」 |
| ✗ | `melee/` `arcane/` `holy/` `shadow/` `moves/` `projectiles/` | 战斗技能，除非某期隐喻正好用到（《滚雪球》的「武器」可以用 slash） |

**限制和用法要点**
- **网格**：特效 1 px = 世界 1 px。UI 类画在 480×270 UI 层（`scale=1`）；`transitions/*` 和 `weather/*` 是 320×180 全屏，画在 320×180 层上 ×6
  （480×270 层要 ×1.5，不是整数，会坏像素）。
- **转场怎么接**：转场是「盖上 → 全遮 → 打开」一个完整过程，**在全遮那段（iris 约 1.0–1.2 s）把底下的画面从 A 换成 B**。
- **英文字**：自带字体只有英文数字（ACHIEVEMENT UNLOCKED / QUEST COMPLETE / LEVEL UP）。偶尔当游戏腔可以，正经信息一律用 pixelkit 中文字体叠，
  带字的特效优先选能改 `text` 的（level-up、combo-counter、crit-number），或者只取它的光效部分。
- **角色类特效**（标 `actor` 的：hit-flash、frozen、petrified、electrified……）是按它自带的 24×38 小人的轮廓画的，导出的精灵表里改色的是**它的**身形，
  直接盖在我们角色上会对不上。头顶类（confused 的问号、charmed 的爱心、exclamation）可以用，但相对我们的大头角色偏小——
  优先用 pixelkit 自己的 `acting.draw_fx`（汗滴 / !! / ? / ♪ / 星星 / 💢 / zZ）。
- **自带背景的**：`weather/fireflies` 带了一片草地和暗色底，不是透明叠加层；用之前先看 `contact.png`。
- **调色**：`palette=[...]` 换主色阶（暗 → 亮），让特效贴合当期配色；默认色偏奇幻高饱和。
- 授权 MIT（可商用，保留 LICENSE 即可）；gallery 里的 Patch Pixel 字体不在 MIT 内，我们不用它。

常用于知识视频的：`ui/achievement`（成就弹窗）、`ui/coin-collect`、`ui/combo-counter`、`ui/confetti`、`ui/countdown`、
`ui/crit-number`（暴击数字 = 惊人数据）、`ui/quest-complete`、`ui/level-up`、`ui/exclamation`（角色头顶感叹号）、
`impacts/hit-flash`、`spawn/poof`（东西消失）、`pickups/*`（获得道具）、`transitions/*`（iris / star-iris / blinds /
diamond-wipe / pixel-dissolve / crt-off / glitch-wipe / shatter-wipe / burn-away / slash-wipe）。

用法：`from pixelkit import pfx; fx = pfx.FX('ui/crit-number', opts={'text': '60T!', 'label': 'WOW'})`（先 `pfx.find('crit')`
查选项），`fx.draw(ui_canvas, t - t0, x, y)`。第一次用会自动烘焙成精灵表并缓存到 `pixelkit/assets/fx_cache/`。
⚠ pixelfx 自带的像素字体只有英文、数字和少量符号：**中文字一律用 pixelkit 的字体画**（特效只负责爆点、光、粒子），
例如 `crit-number` 的星爆放底下，中文数字用 `gameui.big_zh` 叠上去。

## H. 001《深度工作》正片新增（全部 ✅，件在 `pixelkit.hudx`，用例在 `作品/001_深度工作/s1–s6`）

| 手法 | 什么时候用 | 我们的做法 | 工具包 |

| **结界 = 筛子** | 「他不是讨厌科技」这类「有选择地拒绝」 | 红点怪 / App 图标撞上六边形结界被弹开，一封蓝色信件却能穿过去 | 001 `s1_author.barrier_shell` |
