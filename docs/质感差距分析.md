# 质感差距分析：001《深度工作》v4 vs《乌合之众》《金钱心理学》

2026-11-09。对象：我们的 001 v4（5:51），以及「一只索尔」最新的两期《乌合之众》（5:34）和《金钱心理学》（4:58），录屏在 `参考视频/`。
方法：
- 三部片子用同一把尺子量，工具是 `工具包/pixelkit/tools/look_report.py`，用法见第 6 节。
- 每 8–10 秒抽一帧做接触表。
- 挑 14 秒片段，每 0.5 秒一帧看镜头内的变化。
- 局部放大看像素。

> **一句话结论**：差距不在特效、不在像素干不干净，在**美术方向**。参考片先定了一个「世界」（监控录像 / 人生重开游戏），所有画面、UI、转场、颜色都从这个世界里长出来；每半句话由一只手、一个道具完成一个动作。
> 我们是逐句设计镜头，再从工具箱里挑 UI 和特效往上叠，画面元素多，但不属于同一个世界，颜色又满又亮，动作大多由 UI 弹出来代替。

注意：本文修正了 [参考片拆解.md](参考片拆解.md) 的一个判断。那份拆解基于这个系列更早的四期，结论是「统一像素网格是我们的质感优势」。新两期的像素其实比我们的还粗糙（第 2.10 节），但质感明显更好。像素干净只是底线，质感另有来源。

## 1. 实测对比

| 指标 | 乌合之众 | 金钱心理学 | 我们 v4 | 读法 |

| 硬切 / 分钟 | 25.5 | 32.6 | 30.0 | 剪辑频率**差不多**，不是差距 |

| **画面事件 / 分钟** | **62** | **69** | **34** | **只有参考片的一半**：镜头内「发生的事」少 |
| 超过 3 秒无事件的段落 | 18 | 12 | **36** | 我们的「干等」多一倍以上 |
| 最长无事件 | 8.4 s | 11.5 s | 11.4 s（片尾 logo），正片内 9.1 s | |

| **高饱和像素占比** | 3.9 % | 4.1 % | **10.5 %** | 我们约是 2.5 倍 |
| 色彩丰富度（Hasler） | 24.8 | 27.0 | **49.6** | 我们约是 2 倍 |
| **主色集中度** | **0.95** | **0.87** | **0.68** | 参考片的彩色像素几乎都属于同一色相族；我们紫、橙、蓝、红、绿各占一块 |

| 明暗反差 | 20.8 | 17.9 | 20.5 | 差不多 |
| 场景间色调差 | 8.3 | 8.5 | 11.4 | 参考片换场景时色调**变得更少**，全片是一张色卡 |

| 字幕字高 / 画面高 | ≈ 7.8 % | ≈ 7.5 % | ≈ 4.5 % | 我们的字幕小，还是平滑字体 |
| 画面内标签字高 / 画面高 | ≈ 3.5–4 % | ≈ 3.5–4 % | ≈ 1.5–2.5 % | 我们的标签在手机上基本看不清 |

几点口径说明：
- 「画面事件」是相邻帧平均差 > 6 的时刻，0.25 秒内的合并，阈值和 `拆解数据/脚本/rhythm.py` 一致。
- 参考片是录屏，量之前裁掉了播放器界面。
- 发糊程度三部差不多（0.19–0.22）。场景重复用自动聚类测不准（单色片会被整体聚成一类），所以不放进表里，改为人工判断，见 2.3。

## 2. 逐项拆解

每项都写三件事：参考片怎么做、我们怎么做、我们为什么会这样（流程上的根因）。

### 2.1 世界观外壳：UI 从世界里长出来

**参考片**

《乌合之众》整部片是一份**监控录像档案**：
- 每个画面角上都有 `● REC  CAM-03 · 高三(7)班  2022-06-25 19:40:02`，顶部是四个章节标签页。
- 所有信息呈现都是「分析员在看监控」：人头框选（112 s）、红色连线加「隐蔽连接 69」计数（113 s）、上锁的档案格（115 s）、打字机填写档案「决定者：人群」（117 s）、声纹对比（77 s、131 s）。
- 章节卡是一部**电梯的门**：金色装饰艺术风格，门上挂牌写着「卷 02 · 是谁让你转身」，门打开、白光一闪就进入下一章（106–109 s）。书里讲的正是「电梯里所有人转身」的实验。

《金钱心理学》的外壳是一局**「人生重开」游戏**：
- 开局刮中 ¥10,000,000，标题是「人生重开 · 第一局」。
- 商城 App 的「为你推荐」出现在手机里（78–80 s），「第一关 · 1 条提示」是手机里的游戏通知（81 s）。
- 结算界面写着「工作 40 年 / 余额 ¥0 / 自由 0 天」，最后让观众选「存起来（推荐）/ 辞职」（269–277 s）。

两部的 UI 词汇都**少而统一**，全片也就 5–8 种元素，都属于这个外壳。

**我们**

我们有一条规则「注意力 = 读条」，但它是抽象规则，不是一个**地方或媒介**。于是 UI 来自工具箱里的一切：
- 专注条、效率 %、快进键、红色计时器、Boss 血条
- 聊天窗、选择面板、技能栏、时钟环
- 日历、任务清单、圣物底座、全片进度条

在 81 s 的书桌画面里，同时有**四种不同风格的 UI**。

**根因**：先写分镜再挑组件，组件库越大，画面越杂。没有一个「这期世界里允许出现什么」的白名单。

### 2.2 一句话 = 一个身体或道具完成的动作

《金钱心理学》77–90 s 的 14 秒里，按字幕顺序：
1. 「第一样买什么？手又伸向跑车」：戴表的**手**伸向手机，手机里是商城推荐的 V12 跑车。
2. 「先看攻略」：**手指**点开「第一关 · 1 条提示」。
3. 「作者年轻时，在豪华酒店门口泊车」：酒店门口，白手套**手**拿着车钥匙。
4. 「法拉利、兰博基尼，天天从他手里过」：手张开、握紧，钥匙从一把变成一串。
5. 「他记住了几个车主的脸？」：三个车主依次走过。

每个分句都是一个**看得见的动作**，动作的主体是手或道具。这就是它每分钟 69 个画面事件的来源，靠的不是 UI 弹出。

它还大量使用**第一人称的手**：「你」就是画面里那只手（戴表的手、拿手机的手、写便签的手，253 s）。观众被直接放进画面。

**我们**：小橘多数时候是站着或坐着，正面居中。「发生的事」交给 UI 数字变化、粒子、光效。160–174 s 那一段：
- 巨眼画面停 3 秒；
- 两个红点怪在蓝色虚空里停 4.3 秒，只有小标签在变；
- 换到小橘加时钟环，再停 2.5 秒。

**根因**：
- 角色是代码精灵加有限的姿势库，**做不了手和道具的动作**，于是用 UI 来演。
- 「第一人称的手」这个机位我们从来没用过。

### 2.3 场景重复，机位单一

- 《金钱心理学》160 个镜头里，构图几乎不重复：手腕特写、酒店全景、加油站、码头、站台、办公桌俯拍。
- 我们的「书桌前的小橘」出现在作者段、一道题、方法、今晚、收尾五个段落，粗估占全片 1/6 左右的时长，机位几乎都是正面平视。

**根因**：`ep.desk_set` 是一个好用的场景函数，越好用越容易被反复调用；分镜表里也没有「同一场景最多用几次」的约束。

### 2.4 用色：低饱和底色 + 一个有含义的强调色

- 《乌合之众》：棕褐加近黑，**金色 = 秩序 / 档案 / 章节**，**红色 = 人群的感染 / 警报**（113 s 红色连线网）。红色一出现，观众就知道「出事了」。
- 《金钱心理学》：灰蓝加黑白，**金色只给钱和表**。高光时刻才给暖色，比如 229 s 的夕阳站台，那是全片情绪最暖的一场。
- 我们：
  - 每个场景都是紫阴影加橙高光，GPT 插画本身也高饱和、带泛光。
  - 红色同时用于打断、红点怪、Boss 眼、计时器，蓝色同时用于专注条、光柱、夜空。
  - 强调色太多，就没有一种颜色有含义。

量化：我们平均饱和度 0.61，参考片 0.33；主色集中度 0.68，参考片 0.87–0.95。

**根因**：
- GPT 出图提示词写的是「HD-2D lighting with soft bloom, rich depth and atmosphere」，天然偏饱和、偏亮。
- 调色是**逐镜头**做的（GRADE_KEY 等），全片没有一张统一的 LUT。
- 没有色彩剧本（color script）。

### 2.5 明暗：大面积暗部，光只给重点

- 《乌合之众》51% 的像素是暗部，人物站在黑里，只有一束光（275 s 台灯）或一个金框（111 s）。暗部负责「高级感」，也负责引导视线。
- 我们大部分画面是中等亮度的紫色，暗部少。小橘的白脸往往是画面里最亮、最饱和的一块，看久了会累。

### 2.6 特写是重画的，不是放大的

- 《金钱心理学》要特写时（表、钥匙、手机），**单独画一张特写图**，像素颗粒保持在约 6 px（1920 宽）。
- 我们大量依赖 `cam` 推镜（z 1.3–2.3）去「拍近」：
  - 颗粒被放大到 9–14 px，画面变粗。
  - 放大倍数不是整数时，像素块大小还会不一致。
  - 68% 的帧颗粒 ≥ 9 px。
- 另外 233 s 那种「清晰的小橘 + 被模糊处理的背景」，是两套颗粒叠在一起，最显贴纸感。

### 2.7 文字：少、大、像素字、有描边

- 参考片字幕是粗像素字，白字加黑描边，字高约占画面 7.5–8%，每句 1–2 个金色关键词。画面里的标签同样是像素字，字高 3.5–4%，一屏最多一两个。
- 我们：
  - 字幕是平滑的无衬线字体，字高约 4.5%。
  - 画面里的标签（「专注」「效率 50%」「也许有人找你」）字高只有 1.5–2.5%，手机上看不清。
  - 一屏常常有 3–5 处文字。

**根因**：
- 字幕层沿用了开场的样式，没有按像素风重做。
- hudx 组件是按 480×270 的 UI 尺寸设计的，在 1080p 手机竖屏里看偏小。

### 2.8 信息揭示做成悬念装置

《乌合之众》讲「三样东西」时，不是直接列出来，而是：
1. 先出三个上锁的档案格 `?? · ?? · ???`（115 s）；
2. 每说一个词就解锁一格，`传染 → 重复 → 安全感`；
3. 再用打字机在档案上敲「决定者：█」，停一拍，跳出红字「人群」（117 s）。

观众在「等答案」，信息是被**揭开**的，不是被**贴上去**的。同类手法还有框选（112 s）、计数器跳动（「隐蔽连接 69」「复述 11」）、对比实验的 A/B/C 三条线（230 s）。

我们也有命名仪式和读条，但多数信息是直接弹出的卡片。

### 2.9 转场是世界里的物件

- 电梯门开合做章节（乌合之众）。
- 手机屏幕推进成下一个场景（金钱心理学 78–81 s）。
- 档案页翻开做揭示。

转场本身也是外壳的一部分。我们的转场多是硬切、闪白、章节黑卡，形式上正确，但和世界无关。

### 2.10 不是差距的地方（避免改错方向）

| 项 | 实测 | 结论 |
|---|---|---|
| 像素干净度 | 参考片放大看有大量 AI 生图的脏像素、锯齿和抖动残留（站台两人、酒店白手套） | 我们更干净。质感不来自这里，**别再在这上面加投入** |
| 剪辑频率 | 25–33 次/分钟，三部相同 | 不需要切得更快，要的是镜头**里面**有事发生 |
| 特效数量 | 参考片几乎没有粒子 / 泛光类特效 | 我们的特效不少，再加只会更杂 |
| 模糊 | 三部差不多（0.19–0.22） | 整体不是问题；问题在局部（清晰角色叠模糊背景，见 2.6） |
| 场景间换色 | 参考片换场景时**更少**变色调 | 我之前说「参考片每场换一种暖色」不准确：它是全片一张低饱和色卡，暖色只在少数情绪点出现 |

### 2.11 角色气质（风格选择，不算对错）

参考片的主角是写实比例的人（索尔本人的像素形象、勒庞、车主、作家），叙事口吻偏成人，偏纪录片。
大头萌猫天然是可爱和低龄的气质，和「深度工作」这种严肃话题之间有张力。这本身可以是特色，但需要配套：
- 把小橘放进**低饱和、偏暗**的世界里，让它成为画面里唯一的暖色，就像《金钱心理学》里的金色；
- 多用**小橘的手 / 爪**和第一人称视角，少用大脸居中。

## 4. 以后怎么做：新增的「美术方向」阶段

插在 [制作流程.md](制作流程.md) 的「0. 策划」之后、「3. 分镜表」之前。产物是 `作品/<期>/00_美术圣经.md`，在一页之内写完下面六件事，**定完再写分镜**。

### 4.1 世界外壳（必选，一期一个）
- 选一个和书的主题同构的**媒介或地方**：监控录像、游戏存档 / 人生重开、档案馆卷宗、实验记录本、直播间后台、手机屏幕、天气预报、病历、航海日志、法庭卷宗……
  - 例：《深度工作》可以是「专注力实验记录」或「一台旧游戏机的存档」。
- 写出这个外壳的 **UI 词汇表**，5–8 种，比如 REC 角标、档案格、框选、打字机、计数器、章节标签页。**全片只许用这几种**，hudx 里的其他组件一律不用。
- 章节卡和转场也必须是外壳里的物件，比如电梯门、翻页、开机画面、磁带换面。

### 4.2 色彩剧本
- 底色：1–2 个色相族，低饱和（例：棕褐 + 近黑；灰蓝 + 黑白）。
- 强调色：**1 个，写明含义**（例：金 = 专注 / 价值）；第二强调色只在危险或高潮出现（例：红 = 打断）。
- 每章一个明暗基调（亮 / 中 / 暗），情绪最低谷用全片最暗的一段，高潮用全片唯一的一次暖色大面积。
- 全片一张 LUT（后期统一套，不逐镜头调）。数值线见 4.6。

### 4.3 像素与镜头规格
- 一个原生分辨率（世界 320×180）。**推镜最多 1.15 倍**，要更近就**单独出一张特写图**（手、道具、脸）。
- 禁止「清晰角色 + 模糊背景」，景深一律用明暗和饱和度做，不用模糊。
- 统一的材质层由外壳决定，比如监控的扫描线和噪点、游戏机的 CRT、纸张颗粒；全片一层，不叠多种。

### 4.4 动作主体：每句写「谁的手做了什么」
分镜表新增一列「动作」，格式是 **主体 + 动词 + 道具**（例：「你的手 / 划开 / 手机」「白手套 / 张开 / 一串钥匙」）。
- 每个分句至少一个动作；UI 弹出不算动作，只能做补充。
- 「你」优先用第一人称视角的手来演。
- 同一个场景全片最多出现 3 次，每次换机位（正面 / 俯拍 / 过肩 / 特写）。

### 4.5 文字规格
- 字幕：像素字体，白字加 2 px 黑描边，字高 ≥ 7% 画面高，每句 1 个强调色关键词。
- 画面标签：像素字体，字高 ≥ 3.5%，一屏最多 2 处，标签文字 ≤ 6 个字。
- 信息揭示优先用悬念装置：锁格、打字机、框选、计数器，见 [信息呈现手法库.md](信息呈现手法库.md)。

### 4.6 风格样片关（新增的硬关卡）
写完美术圣经后，先做 **30 秒样片**：3–4 句、含 1 个特写、1 个 UI 揭示、1 个转场，然后过三道检查：
1. 和参考片**同尺寸并排**出对比图：同样 6 张帧，左边参考、右边我们。
2. 跑 `look_report.py`，达到下面的线：

   | 指标 | 线 |
   |---|---|
   | 平均饱和度 | ≤ 0.40 |
   | 高饱和像素占比 | ≤ 5 % |
   | 主色集中度 | ≥ 0.85 |
   | 暗部占比 | ≥ 30 % |
   | 画面事件 / 分钟 | ≥ 55 |
   | 超 3 秒无事件段落 | ≤ 4 段 / 分钟（全片 ≤ 15） |
   | 像素颗粒（1920 宽） | 中位 ≤ 7 |

3. 给用户看样片，通过了才铺全片。

### 4.7 GPT 出图提示词改法
- 去掉 `soft bloom`、`rich`、`glowing`，改为 `muted desaturated palette of <底色>, single accent colour <强调色> used only on <对象>, large areas of deep shadow, one hard light source`。
- 每张图带上外壳的视觉特征，比如 `seen through a security camera`、`inside a retro game UI`。
- 特写单独出图：`extreme close-up of a hand holding …, same pixel size as the reference`。
- 出图后先过全片 LUT 再进 Plate 量化，不在单张上单独调。
