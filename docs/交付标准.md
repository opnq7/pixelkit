# 交付标准（每期视频出片前逐条过）

底线 = 参考片（抖音「一只索尔」：《人类简史》《富爸爸穷爸爸》《深度工作》《滚雪球》）的质感；目标 = 比它好。
参考片的实测数据和拆解见 [参考片拆解.md](参考片拆解.md)。下面每条都尽量写成能量出来、能检查的数字。

---

## 一、一句话标准

> **每一句文案都有自己的画面、运镜和声音变化；画面本身在讲解，而不是给字幕配图；好看，而且有趣。**

拆成可检查的四条：

| # | 要求 | 怎么检查 | 参考片水平 | 我们的线 |
|---|---|---|---|---|
| 1 | 每一句都有对应画面 | 分镜表里每个句号级句子至少 1 个画面节拍（新元素 / 新动作 / 新镜头） | 89–94% 的句子有画面变化 | **100%** |
| 2 | 画面不停 | 任意时刻往后 2.5 秒内必有一个可见变化（不算粒子、呼吸这类常驻小动） | 平均 1.5–1.8 秒一次，但有 7–14 秒不动的死区 | **最长静止 ≤ 2.5 s**（金句定格除外，定格要有意为之，≤ 4 s） |
| 3 | 运镜有设计 | 每个镜头写明运镜（推 / 拉 / 摇 / 跟 / 定 / 甩 / 拉远揭示…），不允许没写的默认静止 | 多数是平面图片的平移缩放 | **每镜都写**；同一种运镜不连续用 3 次 |
| 4 | 声音跟画面 | 每个画面节拍都有声音落点（音效 / 音乐重音 / 刻意的静音） | 只有约 3–28% 的切点有音效对齐 | **≥ 90% 的画面节拍有声音落点**，落点误差 ≤ 1 帧 |

## 二、画面

### 美术
- [ ] **质感体检**（2026-11-09 新增，来自 [质感差距分析.md](质感差距分析.md)）。`工具包/pixelkit/tools/look_report.py` 和参考片同尺测，要求：
  - 平均饱和度 ≤ 0.40，高饱和像素 ≤ 5%，主色集中度 ≥ 0.85，暗部 ≥ 30%；
  - 画面事件 ≥ 55 次/分钟，超 3 秒无事件段 ≤ 15；
  - 像素颗粒中位 ≤ 7 px（1920 宽），也就是推镜 ≤ 1.15，特写单独出图。
- [ ] **一个世界外壳**：全片 UI 只用美术圣经里的词汇表（≤ 8 种），章节卡和转场是外壳里的物件。
- [ ] 字幕用像素字体，字高 ≥ 7% 画面高，2 px 黑描边；画面标签字高 ≥ 3.5%，一屏 ≤ 2 处。
- [ ] **真像素**：所有画面在同一个像素网格上（世界 320×180 或 480×270，整数倍放大到 1080p）。GPT 生成的背景必须过 `pixelkit.plates`（限色 + 有序抖动 + 降采样）才能用。不允许出现「伪像素」：糊边、半像素、JPEG 糊块、不同元素像素大小不一致。
  - 参考片的硬伤：同一画面里人物像素块和背景像素块大小不一致；照片转像素的真人头像（《深度工作》里的纽波特、盖茨）和 Q 版小人混在一起。
- [ ] **一期一套美术**：一期视频只用一套角色设计、一套调色、一套 UI 皮肤。主持人 / 主角形象全片一致（发型、配色、比例）。
- [ ] 画面过 `pixelkit.qa`（饱和度、明暗分布、暖高光 / 紫阴影、材质微对比），全景至少 7/9 项在范围内。
- [ ] 每个画面有**光**：至少一个主光方向 + 一个点光或光柱；角色有接触阴影；没有「贴纸感」。
- [ ] 中文字体只用像素字体（zh12 正文 / zh10 小字，最小 zh10）；上线前 `core.missing_glyphs` 查一遍缺字。

### 表演（参考片几乎没有，是我们最大的拉开点）
- [ ] 画面里没有绝对静止的角色：呼吸（1 px）、眨眼（带半闭中间帧）、2–3 秒一次视线变化。
- [ ] 每个动作：预备 → 动作 → 过冲 → 回稳（`acting.Act.beat` / `perform.PoseTrack`）。
- [ ] 角色动作一拍二（15 张/秒），光、水、粒子 30 帧。

### 信息呈现
- [ ] 每个数字、人名、概念都有**画面化**的呈现方式（见 [信息呈现手法库.md](信息呈现手法库.md)），不是只靠字幕。
- [ ] 屏幕上同时出现的文字层 ≤ 2 层（字幕 + 一个信息卡）。画面上的字不要和字幕一字不差地重复——要么是关键词、要么是数据、要么是标签。
- [ ] 信息卡停留 ≥ 阅读时间（0.9 s + 0.12 s/字，`anim.read_time`），且不跨切点弹出（`anim.boxes_cut_lint`）。

### 字幕
- [ ] 一行 ≤ 16 个字（1080p 下），超出就按意群断行或拆成两条。
- [ ] 每句 1 个关键词高亮（暖金色），**高亮在这个词被说出口的那一刻点亮**（用配音 manifest 的 `stress_at` / 逐字时间），不是整句一起亮。
- [ ] 字幕区（底部 18%）不放关键画面元素；需要放时字幕上移或加暗色衬底。

## 三、镜头与节奏

| 项 | 标准 |
|---|---|
| 开场钩子 | **前 3 秒**出现第一个画面事件；前 10 秒 ≥ 10 个画面事件（参考片 13–14 个） |
| 第一个硬切 | ≤ 5 s（参考片 2.3–5 s） |
| 画面事件密度 | 全片平均每分钟 ≥ 35 个（参考片 33–58），**但按段设计**：数据轰炸 / 反问三连 / 问题升级的段落 ≥ 80，低谷 / 顿悟 / 金句 / 结尾 25–40（《Claude Dreaming》打击段 148、低谷段 26） |
| 最长静止 | ≤ 2.5 s；刻意的慢段落（定格、慢推、角色小表演）≤ 4 s |
| 核心概念命名仪式 | 每期的核心概念（「书里管这叫 X」）有且只有一次命名仪式：名词卡 / 道具登场 + 推镜 + 说到名字最后一个字时大字砸屏 + 音乐落点 |
| 情绪弧线 | 痛点 → **真的低的低谷**（暗、静、慢）→ 概念登场 → 变化 → 新眼光看生活 → 回扣开头；低谷段音乐抽到几乎没有 |
| 切点位置 | 切点落在**意群边界**（逗号 / 句号前后 0.2 s 内）或**重读词上**，不在一个词中间切 |
| 转场 | 段落之间用有动机的转场（从画面里长出来：推进屏幕 / 拉远揭示 / 关卡地图 / 追光），同一种转场全片 ≤ 3 次 |
| 章节 | 每个章节有章节卡（≤ 1.5 s）+ 顶部章节进度条，观众随时知道「第几关、还剩几关」 |

## 四、声音

| 项 | 标准 |
|---|---|
| 成片响度 | −14 ~ −16 LUFS（抖音），真峰 ≤ −1 dBTP |
| 人声 | `导演配音.py` 出的 voice_master（−16 LUFS），全片人声清楚可懂，最响的音效不盖过人声 |
| 配乐 | 说话时配乐比人声低 15–20 dB（参考片 15–17 dB）；**不说话的空档配乐抬起来 6 dB 左右**再压回去（ducking） |
| 音乐结构 | 每个章节换配乐或换配器；金句前 0.3–0.8 s 音乐抽掉（静音制造重量）；章节卡用一个短 sting；**全片最响的时刻后面紧跟全片最静的时刻**（高潮后 1–2 s 黑场 / 定格 + 全静音） |
| 音效密度 | 跟段落性质走：数据 / UI / 喜剧段每个弹出都有声；情绪 / 顿悟段几乎不放音效，交给音乐和配音 |
| 音效 | 每个画面节拍一个音效落点（弹出 = pop、划入 = swish、盖章 = stamp、数字滚动 = digit_ticks、对错 = ding/deny…），音效库见 `pixelkit.audio.cues` + `工具包/素材库/音效` |
| 音效对齐 | 音效起点和画面事件同一帧；「重读词 → 画面 → 音效」三者对齐到同一时刻 |
| 底噪 | 每个场景有环境底（room tone / 风 / 城市），避免纯数字静音的「真空感」，除非刻意 |

## 五、配音

见 [配音导演规范.md](配音导演规范.md)。出片前：
- [ ] 每一句都写了情绪 / 语速 / 停顿，重读词标了 `**`。
- [ ] `report.txt` 无 ⚠ 错字；多音字、人名、数字、年份全部人工听过。
- [ ] 说话时语速 4.3–4.8 字/秒（参考片 4.6–4.7），含停顿 3.9–4.4 字/秒；单句 > 6 字/秒的拆句。

## 六、出片前技术检查

```bash
python -m pixelkit.qa flicker 成片.mp4          # 单帧闪烁
python -m pixelkit.vqa 成片.mp4 --cuts <切点>    # 非切点的大跳变、切点前一帧提前冒出来的东西
```
- [ ] 1080p / 30 fps / H.264 CRF ≤ 18 / AAC 256k / `+faststart`
- [ ] 抽 10 张静帧看：没有缺字方块、没有越界的 UI、没有被字幕挡住的关键信息。
- [ ] 从头到尾完整看一遍，**关掉声音看一遍**（画面自己能讲明白吗？），**只听声音听一遍**（不看画面也舒服吗？）。
