## 2. 系列公式（四期几乎一样的骨架）

```
冷开场（0–20 s）   一个具体、反常识的场景或数字           「一顿午饭 1900 万美元」「拳王挣了 3 亿，破产了」「猴子天堂」「上帝扔下一件武器」
书登场             「这本书讲的就是它：《XX》」+ 作者卡 + 一个背书（销量 / 授权 / 推荐人）
叠甲 / 收窄范围    「先叠个甲，今天不教你炒股」「我不打算全讲，只讲透一件事」
结构               「一共三关」/「第一话」，配关卡地图或章节卡
每一关             问题 → 书里的故事或数据 → 反常识结论 → 「放到你身上」→ 一句金句
方法               「三张赎回券」「送你三步，今晚就能开始」：编号、可马上做
客观               「这本书也有人不服」：一条争议 + 我的看法
回收               回到开场的场景 / 问题（「那一百万，现在你会买哪辆车？」）
固定结尾           评论区一个问题 → 「视频只有几分钟，装不下一整本书 …… 读完一本书，就是一场自救。这里是一只索尔，我们下一本书见。」
```

反复出现的文案句式（可直接学）：
- **「放到你身上」**：每个书中例子之后，立刻换成观众的日常（背单词、健身、分期买手机、凌晨改方案）。这是让知识「和我有关」的关键转折。
- **「书里管这叫 X」**：先讲现象，再给名词（老鼠赛跑、能力圈、内部计分卡）。名词出现时画面上同步打出名词卡。
- **「不是 A，是 B」**：「不是你变笨了，是你桌上的东西变了」「雪球最怕的不是慢，是晃」。金句几乎都是这个结构。
- **数字要换算到生活**：「一顿午饭 1900 万美元 ≈ 普通上班族不吃不喝干一千多年」。

## 3. 文案和画面怎么配（做得好的，要学）

1. **画面演名词**：一句话里的核心名词直接成为画面主体。「一张印着头像的纸」→ 一张钞票，头像位置贴「头像」标签；「挤进地铁」→ 被人群夹住的脸 + 07:00。
2. **数字一律上屏**：每个数字都有对应 UI（金框数字、计数器、计时器、日历格子）。观众「看见」数字而不只是听见。
3. **排比 = 同一构图换内容**：「是车吗？是工厂吗？是员工吗？」三个画面构图一致，标志始终悬在同一位置——形式本身在讲「换了都还在」。
4. **关键词高亮**：字幕一句 1–2 个词金 / 橙色高亮，高亮的往往就是画面正在演的那个东西。
5. **主持人锚点**：讲「元信息」（这句话不是我编的 / 我自己的看法 / 评论区告诉我）时回到主持人画面（律师事务所），讲内容时离开。观众靠它分清「书说的」和「我说的」。
6. **每期一个视觉隐喻贯穿**：仓鼠轮（老鼠赛跑）、雪景球 + 武器（复利）、书页（故事）、拳台 + 游戏 HUD（财富人生）。隐喻在结尾被回收（「前十年像木棍，后十年是一把神剑」）。
7. **游戏化包装**：关卡 / 第 X 话 / Lv99 / 赎回券 / 暂停菜单 / 背包 / 计分卡——把读书包装成「通关」，观众有进度感。

## 5. 声音

- **配乐**：全片一条低音量配乐床（说话时低 15–19 dB），节奏型的芯片 / 拨弦乐；**章节换段落时换配乐或抽掉**（人类简史 0:10 处音乐整个抽掉 5 秒，0:16 换新的节奏型）。
- **章节 sting**：章节卡前 1–1.5 s 空白 + 宽频 whoosh / 上扬音。
- **UI 音效**：信息弹出时有短促的「哔 / 啵」类提示音（频谱上是高频竖线）。
- **问题**：音效和切点、和画面事件对得不紧：只有 3–28% 的切点在 ±0.12 s 内有音效。很多弹出是「无声」的。

## 6. 配音

- 真人感很强的讲述腔，语速均匀（说话时 4.6–5.0 字/秒），句间停顿短（中位 0.24–0.36 s），章节前有 1 s 以上的长停顿。
- 优点：不拖、信息密、像朋友聊天。
- 不足：起伏小，铺垫句和结论句几乎同速，金句前没有足够的「蓄力停顿」；听满 5 分钟会略平。

## 7. 做得没那么好的地方 → 我们怎么超过它

| # | 问题 | 例（时间点） | 我们的做法 |
|---|---|---|---|
| 1 | **伪像素、像素尺度不统一**：AI 生图直接放大，像素块大小不一；粗块人物和细密背景同框 | 人类简史 0:00（大块猴子 vs 细冰箱）、1:51（满屏大脸）；深度工作 0:03（超精细巴菲特）vs 0:06（Q 版小人） | 所有画面在**同一个像素网格**上（`pixelkit`，GPT 背景过 `plates` 量化）。这是我们最直观的质感优势 |
| 2 | **画风跳**：照片转像素的真人头像和 Q 版角色混用；同一个「你」在不同镜头长得不一样 | 深度工作 1:21 纽波特、1:48 盖茨（照片感）；0:15 / 0:39 / 1:09 主角造型不一致 | 一期一套角色设定，名人也画成同一画风的像素小人（3–4 个识别特征：盖茨 = 眼镜 + 灰发 + 毛衣） |
| 3 | **角色不演**：人物基本是静态贴图，只有平移缩放；主持人每次回来都是同一张图 | 人类简史 律师主持人 0:27 / 0:36 / 1:57 / 5:21 几乎同姿势 | 表演层：呼吸、眨眼、视线、预备-动作-过冲、一拍二（`perform` / `acting`）。主持人每次回来换动作 |
| 4 | **信息死区**：一句长句 + 一张图慢推 6–13 秒，眼睛没事做 | 人类简史 1:15–1:21、1:39–1:46；富爸爸 1:51–2:00（8.4 s）；滚雪球 0:25–0:34 雪景球 8.3 s（跨 3 句） | 每个意群一个画面节拍，**最长静止 ≤ 2.5 s**；分镜表逐句检查 |
| 5 | **字幕和画面上的字重复**：大字卡和字幕一字不差，观众读两遍 | 深度工作 1:06（大字 = 字幕）；人类简史 4:42「国王是神的儿子」 | 画面上的字只放关键词 / 数据 / 标签；整句只在字幕里 |
| 6 | **文字层太多**：顶部章节条 + 信息卡 + 字幕 + 标签同时在屏 | 人类简史 2:12、3:24 | 同时最多 2 层文字；章节条做薄 |
| 7 | **音效稀、不对点**：多数弹出无声；切点上有音效的只有 3–28% | 富爸爸 全片切点几乎无音效 | ≥ 90% 画面节拍有音效落点，误差 ≤ 1 帧；音效时间从配音逐字时间轴来 |
| 8 | **配音起伏小** | 全系列 | 逐句导演：情绪 / 语速 / 停顿 / 重读，金句前蓄力停顿（`导演配音.py`） |
| 9 | **光是平的**：大多数画面是一张均匀打光的插画，聚光灯是画死在图里的 | 全系列 | HD-2D 光照：主光方向、点光、god rays、bloom、接触阴影，光可以随剧情变（开灯 / 入夜 / 聚光） |
| 10 | **隐喻用一次就丢** | 人类简史「标志」幽灵、深度工作「黄金」 | 一期一个主隐喻贯穿到底，结尾回收；次要隐喻不超过 2 个 |

## 8. 结论：底线和目标

**照抄的（已经被验证有效）**：系列骨架（第 2 节）、「放到你身上」、数字上屏、关键词高亮、主持人锚点、游戏化章节、每期一个隐喻、画面每 1.3–1.8 秒一次变化、常驻缓推、章节前 1 秒静音 + sting、配乐低于人声 15–18 dB。

**超过它的（我们的差异化）**：真像素统一网格、角色会演、HD-2D 光、零信息死区、音效逐帧对点、逐句导演的配音。
