# 叙事方法（整合版）：七部参考片学到的，怎么讲一本书

2026-11-09。这是**写稿前必读**的总纲。它把三份拆解合在一起，再配上新两期的逐句拆解：
- [参考片拆解.md](参考片拆解.md)：节奏和数字，旧四期；
- [顶级参考学习笔记.md](顶级参考学习笔记.md)：《Claude Dreaming》；
- [有趣从哪来.md](有趣从哪来.md)：新两期逐句拆解。

样本：
- 「一只索尔」旧四期：《人类简史》《富爸爸穷爸爸》《深度工作》《滚雪球》；
- 新两期：《乌合之众》《金钱心理学》；
- 无配音故事短片《Claude Dreaming》。

转写在 `参考视频/拆解数据/转写/`，联系表在 `参考视频/拆解数据/联系表/` 和 `质感体检_2026-11-09/`。

> **一句话**：讲书有三个层级。
> - **L1 讲书 + 隐喻 + 放到你身上**：旧四期在这一层，我们 001 也在这一层，而且比旧四期还弱一点。
> - **L2 造一个观众身在其中的情境，书在情境里发生**：新两期在这一层。
> - **L3 再给它一条情绪弧线**：失败 → 低谷 → 拿到工具 → 升级 → 回到现实，用开头那句话收尾。这是《Claude Dreaming》做的。
>
> 我们下一期要直接写到 L2，并借 L3 的弧线。

## 1. 七部片子一张表

| | 冷开场（前 15 秒） | 题眼 / 隐喻 | 外壳（观众在哪） | 证据怎么给 | 结尾回收 | 评论区引导 |
|---|---|---|---|---|---|---|
| **人类简史** | 猴子寓言：「把香蕉给你，死后去猴子天堂」→ 三个「你会为了……」排比 | **故事**：钱、公司、高低都是故事 | 无，主持人在律师事务所讲 | 算账（60 万亿 vs 6 万亿）、标致排比、汉谟拉比法典 | 「凌晨还在改方案时，问一句：会不会痛？」 | 你现在拼命的是哪一个故事？ |
| **富爸爸穷爸爸** | 泰森挣了 3 亿多，2003 年破产（拳击游戏 HUD） | **钱往哪边流**：资产 / 负债两栏 + 老鼠赛跑 | 半个：游戏节目选车（聚光灯，5 万 vs 50 万） | 先让你选车 → 百万富翁调查反转 | 「泰森挣了三亿，输给了负债。那一百万，现在你会买哪辆车？」 | 五万还是五十万？ |

## 2. 系列的不变量（已经被验证过，照着用）

七部都有，或者六部「一只索尔」都有的东西：

1. **冷开场要具体、反常识、带数字或悬念**，而且第一个「你」在 15 秒内出现：
   - 「1900 万美元一顿饭 → 那你的时间呢？」
   - 「泰森挣了 3 亿，破产了」
   - 「上帝扔下一件武器」
   - 「你会怎么站？」
   - 「数数，几个零？」
2. **一个贯穿全片的隐喻，开头立起来，结尾翻过来用**：
   - 木棍 → 神剑
   - 拍走 → 赎回
   - 故事 → 会不会痛
   - 转身 → 不转身
   - 刮彩票 → 发工资
3. **三段式**，每段的固定节拍是：问题 → 书里的证据 → 反常识 → **放到你身上** → 金句。
   - 金句几乎都是「不是 A，是 B」或者对仗：
     - 「雪球最怕的不是慢，是晃」
     - 「有钱，是你花得起；富有，是你没有花」
4. **证据优先用「人 + 具体数字」**：巴菲特 11 岁卖股票、65 岁以后的九成身家、泰森的 3 亿、加油站老头的 800 万。抽象的研究结论也要换算成人能感受的量，比如二十多万年、47 秒。
5. **先让你猜，再揭晓**：一分钱翻倍第 25 天是多少、5 万还是 50 万的车、谁更有钱、你会怎么站。
6. **评论区引导 = 结尾那个问题，用隐喻的词来问**。观众答得出来，而且答案是一个短词或数字。
7. **固定结尾**：「视频只有几分钟，装不下一整本书……读完一本书，就是一场自救。」品牌是稳定的。

## 3. 系列的进化：旧四期 → 新两期改了什么

这是我们最该学的。同一个作者，从 L1 走到了 L2：

| | 旧四期（L1） | 新两期（L2） |
|---|---|---|
| 观众的位置 | **听众**：「你会为了……」「放到你身上」 | **当事人**：「你在桌子底下刮了一张彩票」「你会怎么站？」 |
| 主持人 | 律师事务所里的讲解员，每段回来讲一次 | 主持人就是那个「你」，在电梯里、在工位上 |
| 隐喻 | 一个**名词**加它的词族（故事、雪球、赎回券） | 一个**动作**（转身、重开），有选择、有后果 |
| 游戏元素 | 装饰：拳击 HUD、关卡地图、Lv99 | 语法：菜单选择、结算、成就、攻略、随机事件、隐藏结局 |
| 证据 | 讲出来，配图 | 演出来，数字在动，有反转 |
| UI 文字 | 名词卡、数字卡，大多和配音重复 | 第二条台词，补刀（自由 0 天、道歉 0） |
| 道具 | 一次性 | 道具账本，同一个道具换两三次意思 |
| 方法 | 「第一张赎回券」口头加卡片 | 外壳里的实物（便签贴在桌上、监控室的观看人数） |
| 「有人不服」段 | 三期有，《深度工作》换成了「我不保证它能让你成功」 | **删了**，换成书里自己的另一面（「同一群人，也能比任何一个人都勇敢」） |
| 颜色 | 每个画面都给满 | 留到答案出现时 |
| 结尾 | 回扣开头的问题 | 回扣开头的**道具和选择**，再接一次真心（父母、身边那个人） |

**关键转变**：从「我来给你讲这本书」变成「我们来玩一局，书是攻略」。

## 4. 《Claude Dreaming》补上的三样

1. **情绪弧线**：失败 → 真的低的低谷（暗、静、慢）→ 有人递来一个工具（命名仪式）→ 升级 → 用新眼光看世界（高潮，全片唯一一次风格突破）→ 硬切静音 → 回到现实 → 用开头那句话笑着收尾。
   新两期其实也有这条弧线，《金钱心理学》是「自由 0 天 → 上帝重开 → 三个成就 → 门打开（全彩）→ 父母」，只是没那么戏剧化。
2. **笑点打断煽情**：讲完很正的一句，马上给一个短反应（「……这算安慰吗？」「……啥？」）。
3. **节奏按段设计**：打击段每分钟 148 个画面变化，低谷段只有 26 个；最响和最静挨着放。

## 5. 同一本书的对照：旧参考片《深度工作》vs 我们 001

我们选了参考片做过的同一本书，正好可以逐项比：

| | 参考片（4:31） | 我们 001（5:51） | 判断 |
|---|---|---|---|
| 冷开场 | 一个具体事件：巴菲特午餐 1900 万美元，换算成「普通上班族不吃不喝干一千多年」，再一转：「那你的时间呢？今晚刷了三小时手机，换回来几个点赞」 | 一个抽象判断：「最贵的东西正被你免费送出去，它是注意力」，再立一个游戏规则「读条」 | **参考片赢**。具体事件 + 换算 + 转向「你」，15 秒内三步到位 |
| 隐喻 | 拍卖 / 赎回：卖时间、拍走、赎回券、赎回来 | 读条，再加大招、普攻、副本、蓝条 | 两边都是一个**词族**，但参考片的词全是**观众做的动作**（卖、拍走、赎回），不用解释；我们的词是**名词**，每个都要一句定义（「一种是普攻：……」） |
| 痛点证据 | 47 秒（三个年代的同一张书桌）、十亿人 × 两小时 = 二十多万年 | 「被打断要二十多分钟才能回来」 | 参考片的数字更狠，还做成了画面对比；我们的证据只有一句 |
| 作者 | 一句话：五点半下班 + 写得比加班的同事还快 | 作者段 8 句：怪人设、跟不上时代吗、结果……、不是讨厌科技…… | 我们讲得更细，反差也更好（「这种人该跟不上时代吧？」），但用了 30 秒 |
| 方法 | 三张赎回券，都很具体、反常识：钉死下班时间、从分心里休息、悄悄停用三十天 | 开副本、大招普攻分开打、练蓝条，再加一个今晚的练习 | 参考片的方法更**反常识**；我们的方法更像常识，用游戏词重新包装了一遍 |
| 结尾 | 「明天拿起手机前问自己：这一小时是被拍走了，还是赎回来了？」 | 「你的注意力放在哪里，你的人生就长在哪里」 | 参考片把隐喻变成**明天早上的一个动作**；我们的是一句金句 |
| 我们赢的地方 | — | 情绪弧线更完整（最低谷、命名仪式、读满高潮）、角色有表演、音效对点、真像素 | 这些是制作层面的，不是叙事层面的 |

**结论**：我们 001 在叙事上处于 L1，而且在「开场具体性」「隐喻是不是动作」「证据冲击力」「方法反不反常识」这四点上，输给了同一本书的旧版参考片。
制作上我们更精细，但精细的制作在讲一个更平的故事。

## 6. 整合后的叙事设计流程（写稿前做完，大约半天）

### 第 1 步：一句「反常识核心」
用「大多数人以为 A，其实是 B」写出这本书最反直觉的一句话，下面每一步都为它服务。
- 金钱心理学：大多数人以为钱的回报是买东西，其实是**不用做不想做的事**。
- 乌合之众：大多数人以为自己在独立选择，其实**一直在跟着转身**。

### 第 2 步：题眼动作
找一个动作，三条都要满足：
- **画得出**：一帧就能看懂；
- **人人做过**；
- **里面有选择**。

先写 5 个候选，再挑一个。这个动作要能串起全片：
- 开场：你做了这个动作（或者正要做）。
- 中段：书解释你为什么会做它。
- 结尾：你可以不做 / 换一种做法。
- 评论区：问你会不会做。

### 第 3 步：外壳和映射表
选一个外壳：观众在哪里、扮演谁。然后填映射表：

| 书里的东西 | 外壳里的东西 |
|---|---|
| 核心观点 ×3 | 成就 / 卷宗 / 关卡 |
| 书里的数据 | 攻略 / 化验单 / 监控记录 |
| 现实里的诱惑或风险 | 随机事件 / 警报 |
| 结论 | 隐藏结局 / 结案 |
| 方法 | 通关秘籍 / 处方 |
| 评论区问题 | 新的一局 / 新的选择 |

外壳同时决定美术圣经里的 UI 词汇表和材质，见 [质感差距分析.md](质感差距分析.md)。

### 第 4 步：情绪弧线节拍表（按 5 分钟片长）

| 时间 | 节拍 | 要做到 |
|---|---|---|
| 0:00–0:15 | **你在现场** | 现在时，第二人称，一个具体场景，一个数字或悬念，一个问题 |
| 0:15–0:45 | **第一次代价** | 你凭本能做了选择，外壳给出结果。要一个扎心的 UI，比如「自由 0 天」「对话 0」 |
| 0:45–1:00 | **书登场 = 包袱或命名仪式** | 书是对前面那个代价的回答（「上次你跳过了它」）；核心概念全片只命名一次 |
| 1:00–3:20 | **三关** | 每关：情境 → 让你猜 → 证据演出来（数字在动）→ 反转 → 放到你身上（具体到时间、地点、动作）→ UI 补刀 → 金句 →「成就解锁」 |
| 2:30 前后 | **真的低的低谷** | 暗、静、慢，「也许就是我不行」，节奏降到每分钟 25–40 个画面变化 |
| 3:20–3:50 | **回收 + 解锁** | 开头的道具和选择换了意思回来；全片第一次给颜色或温度 |
| 3:50–4:15 | **真心** | 只讲人：父母、朋友、过去的自己。不讲书 |
| 4:15–4:40 | **方法是外壳里的实物** | 2–3 条，要反常识，要具体到今晚 / 明早的一个动作 |
| 4:40– | **评论区 = 外壳里的新一局** | 用题眼动作来问，答案是一个短词或数字 → 固定结尾 |

另外两条：
- 快段（问题升级、数据轰炸）每分钟 80 个以上画面变化，慢段每分钟 25–40 个；
- 全片最响的那一刻后面，紧跟最静的一刻。

### 第 5 步：道具账本
至少 3 个道具，每个出现 2–3 次，每次意思不一样。至少一个要在结尾和评论区引导里兑现。

### 第 6 步：三栏剧本
格式是「配音 / 画面里发生了什么 / UI 台词」，三栏一起写，见 [有趣从哪来.md](有趣从哪来.md) 第 4 节。

写稿规则：
- 配音一句 ≤ 12 字，像在描述画面正在发生的事；
- 每 3–5 句来一个问题、一次反转，或一个让人猜的停顿；
- 举例不用「学生……/ 打工人……」的清单，改成一个具体到时间、地点、动作的小场景；
- 讲完一个很重或很绕的点，给一个短反应（「……啥？」「手在抖，对吧？」）；
- 画面和文案的关系：L1 配图 ≤ 30%，L3 补刀每 30 秒至少一次。

### 第 7 步：稿子自检（每一项都要「是」才能去配音）

- [ ] 前 15 秒：具体场景 + 第二人称 + 数字 / 悬念 + 问题？
- [ ] 题眼是一个**动作**，画得出、人人做过、有选择？
- [ ] 隐喻用的词都是观众**做的动作**，不需要一句一句下定义？
- [ ] 书登场是一个包袱，或者是对前面代价的回答，而不是「这本书叫……作者是……」？
- [ ] 三关的每一关，都有一次「先猜再揭晓」和一个会动的数字？
- [ ] 至少一个证据被演成了小剧场（实验 / 故事 + 反转）？
- [ ] 方法里至少一条是反常识的？
- [ ] 道具账本 ≥ 3 个道具，每个至少换过一次意思？
- [ ] UI 台词里至少 5 处补刀（0 / 1 收尾、反讽、伏笔）？
- [ ] 有一次真的低的低谷、一次颜色 / 温度解锁、一次只讲人的真心？
- [ ] 评论区引导用题眼动作来问，答案是一个短词或数字？
- [ ] 把配音栏单独念一遍，像在讲一件正在发生的事，而不是在讲课？
