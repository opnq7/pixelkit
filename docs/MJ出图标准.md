# MJ 出图标准（Midjourney 8.2 → 像素舞台）

> 2026-11-13，Claude 在用户的 MJ 账号上实测得出。样片和素材在 `测试/MJ探索_理发店/`。
> 目标：好看、自然、有质感，并且**服务旁白**。MJ 负责「长什么样」，代码负责「动、光、时间」。

## 0. 先知道的一件事：账号默认风格化是 600

用户账号的默认设置是 `风格化 600`、`混沌 10`。提示词里不写 `--s` 时就按 600 出图，结果是油画或写实电影画面，像素锚点几乎不起作用。

- 用户自己出图时由用户决定风格化，**给用户写的提示词里不带 `--s`**。
- 做像素底图、角色、道具这类生产素材时，**在提示词里明确写 `--s`**，覆盖账号默认值。

## 1. 参数结论（同一提示词、同一种子 `--seed 505` 对照）

| 参数 | 结果 | 用法 |
|---|---|---|
| `--s 0` | 平涂海报感，对比强、偏亮偏艳 | 不用 |
| `--s 50` | 大色块、硬边光影、像素簇明显 | **不再当默认值**。用户评价（2026-11-13）：「开低了图不好看，没质感」。像素感强，但画面平、没有光和材质 |
| `--s 150` | 细节和光更丰富，仍是游戏背景画法 | 候选区间的下限 |
| `--s 300` 及以上 | 越来越像油画 / 写实电影画面 | 不一定不能用：我们会把图降到 320×180 并量化到 48 色（`plates`），网格和色阶由这一步重新给出，MJ 只需提供光、材质和构图。上限待测 |

**默认值 `--s 500`**（用户定，2026-11-13）。不行再往低调。往低调的情况，比如像素感太弱、过完 `plates` 变糊，或者人物和画面开始走写实油画。调整时每次降 100 左右，判断标准是**过完 `plates` 降到 320×180 之后**的样子，不是 MJ 原图。
| `--raw` | 8.2 里没有作用（同种子下和不加完全一样） | 不写 |
| 画风锚点（Octopath / LucasArts / 320x180 / Wadjet Eye） | 风格化 600 下几乎没有区别 | 风格化压低后再比较 |
| `--seed` | 只能固定构图倾向，**留不住同一个人**（换发型后脸和性别都会变） | 只用于对照实验 |
| `--v 8.2` | 默认版本 | 保留 |

## 2. 提示词写法

**底图（空舞台）**
```
Pixel art point-and-click adventure game background, side view of <地点>, <2–5 个具体物件>,
<一个明确的光源和它照到的地方>, <主色> and <辅色> palette, hand-placed pixels,
limited 32-color palette, visible pixel grid, subtle dithering, empty room
--no people, text, letters, realistic, photo, 3d render, smooth gradients --ar 16:9 --v 8.2 --s 500
```
- **人物要画进图里**（v3 结论，推翻了 v1/v2 的做法）：人和景一次画出来才是同一种画法和光。人物要「动」时，用快速编辑出几个状态切换，不要用代码画人贴上去。分类做法见 [画面分类与做法.md](画面分类与做法.md)。
- 只有纯背景（之后要叠 UI 或说明装置）的画面才出空舞台。
- **正侧视或一点透视**：仰视、俯视、大斜角好看，但人物放进去很难自然地动。
- **光源要明确、面积小**（窗、灯、屏幕），`plates` 会自动找出来做闪烁和光晕。
- **不画粒子**（雨、雪、灰尘），这些由代码加，画进去就是冻住的。

**角色：精致可爱的像素小人**（用户定，2026-11-13）。写实 6 头身的插画缩小后「不够精致可爱」，作废。用户点名喜欢的三套设定图：兜帽提灯人（s550）、白发老科学家（s25）、戴眼镜的狐狸学者（s550）。它们的提示词有这几个共同点：

| 要素 | 写法 | 作用 |
|---|---|---|
| 卡片类型 | `Pixel art character design card / character sheet` | 让 MJ 按「设定图」排版，不画场景 |
| 比例 | `chibi proportions about 2.5–3 heads tall` 或 `round-headed` | 头大身小，可爱的来源 |
| 小尺寸可读 | `designed to stay readable at 40–48 pixels tall`、`strong simple silhouette` | 逼它用大块形状，不画碎细节 |
| 像素画法 | `crisp deliberate hand-placed pixels`、`clean 1-pixel dark outline`（低风格化时再加 `64x64 pixel sprite style, chunky visible pixels`） | 原生像素感、描边 |
| 色彩 | `muted <主色> palette`、`limited 12-color palette`、`<一个东西> the only accent color` | 低饱和 + 一个记忆点颜色 |
| 排版 | `top row full-body front, side and back views, bottom row <N> head expressions / gestures: ...`、`consistent proportions in every view` | 三视图 + 表情 / 手势，同一个人 |
| 背景 | `flat neutral grey background, no text` | 方便抠图 |

```
Pixel art character sheet, <人物：物种 / 年龄 / 发型 / 衣服 / 一个道具>,
chibi proportions about 3 heads tall, top row full-body front, side and back views,
bottom row six head expressions: calm, curious, shocked, smug, sad, <一个和本期有关的>,
consistent proportions in every view, muted <主色> palette, <道具> the only accent color,
crisp deliberate hand-placed pixels, clean 1-pixel dark outline, strong simple silhouette,
designed to stay readable at 48 pixels tall, flat neutral grey background, no text
--no text, letters, realistic, 3d render, smooth shading --ar 16:9 --v 8.2 --s 500
```
- 风格化：s500 左右更有质感、更柔和（狐狸、兜帽人）；s25–100 像素颗粒更硬更「游戏」（科学家）。两种用户都接受，按镜头需要选。
- 做动画用的动作图：排版改成 `one row of six full-body poses, all in strict side view facing left: ...`，把需要的动作直接写进去（走路两步、坐下、吃、震惊……）。
- 纯灰底方便抠图。缩到舞台尺度时**不要用平均缩小**（会糊掉描边），要按 MJ 图里的像素格取样。

## 3. 同一个人的「前后状态」：用 MJ 编辑，不用种子

1. 出一张满意的图（比如长发坐在镜子前）。
2. 打开大图 → 右侧「编辑 → 快速编辑」，图片会挂到输入框的 **Attach to prompt** 槽里。
3. 写一句只改要改的东西：`same person, same mirror, same pixel art style, but the hair is now cut very short, shocked wide-eyed expression`。
4. 结果：镜子、背景、披风、椅子、构图全部保留，同一个人，只改发型和表情。

这就是「稍微修一下 → 二十分钟后」这类前后对比的做法：两张图之间用代码做硬切、叠化或延时。

## 4. 颜色：MJ 的底图太艳，必须调色

| | 平均饱和度 | 线 |
|---|---|---|
| MJ「琥珀加墨绿」底图（原图） | 0.77 | 交付标准 ≤ 0.40，参考片 0.33 |
| 同种子 + 提示词里写低饱和（见下） | **0.58**（亮度不变） | |
| 样片 v1 clean（只加辉光、暗角、颗粒） | 0.83 | |
| 样片 v2 grade（饱和度 ×0.5、对比 1.18、暗角 0.5） | 0.56，但平均亮度 0.18、暗部 67%（参考片 0.24–0.29、35–51%），太暗 | |
| **样片 v2 grade2**（饱和度 ×0.4、对比 1.12、提亮 ×1.14、暗角 0.32） | 0.51；亮度 0.24、暗部 57%、反差 24.8（参考片 18–21） | 目前最好的一版 |

注意：冷暖分离（暗部偏青、亮部偏暖）本身会把饱和度加回去，所以光靠调色压不到 0.40，必须先在源头降饱和。

**两步走**：
1. **源头降饱和**，在底图提示词里加：`muted desaturated faded colors, <尘土琥珀> and <灰绿> palette, low saturation`，`--no` 里加 `vivid colors, saturated`。
2. **轻调色**：饱和度 ×0.65 左右、对比 1.1、暗部偏青、亮部偏暖，暗角 ≤ 0.35，不要靠压暗来降饱和。

## 5. 代码让画面活起来的手段（样片里都用了）

| 手段 | 做法 | 对应旁白 |
|---|---|---|
| 转灯 | 在转灯的玻璃区域里画斜条纹，相位随时间走；硬边 4 级明暗 | 理发店的「招牌动作」 |
| 浮尘 | 只在阳光照到的墙面上可见的单像素粒子 | 午后、安静 |
| 延时 | 原光柱变暗、移位后的新光柱变红、全局转黄昏、转灯加速、曝光一拍二地闪 | 「二十分钟后」 |
| 碎发 | 一拍二地一簇簇出现在椅子周围 | 时间过去了、剪了很多 |
| 人物 | 呼吸（每 3.6 s 沉 1 px）、头发分 5 档变短 | 剪完了 |
| 剪辑 | 远景 → 硬切镜中特写；切入时 1.12 → 1.0 的「吓一跳」回拉加震屏，然后慢推 | 「他没听错，你也没说错」的笑点 |
| 特写小动作 | 眨眼（半闭、全闭、半闭各 1–2 帧）、飘落的碎发 | 让静止的 MJ 图活起来 |
| 辉光 | 在 320×180 网格上算辉光再量化成色阶，辉光本身也是像素 | 不破坏单一网格 |

## 6. 已知的坑

- **字幕要画在屏幕层**，放在调色之后；画在世界画布上会被推镜推出画面、还会被调色。
- MJ 截图时鼠标指针会被拍进去：先把鼠标移出图片再截，或者用代码修掉。
- 浏览器截屏抓不到正在播放的视频（是黑的），MJ 的「动画图像」要下载后才能评估。

## 7. 样片暴露的问题和下一步

1. **画面事件太少**：v2 只有 6.4 次/分钟（参考片 62–69，标准 ≥ 55）。转灯、浮尘、延时都是渐变，不算「事件」。下一版要按字落点：每个关键词一个看得见的变化（一簇头发落地、剪刀合上、转灯一顿、价签弹出……）。
2. **代码画的远景小人太粗**：白披风像方块。改用 MJ 出的「坐在椅子上的背影」精灵图（写实比例那张），抠图、降到舞台尺度再放进去。
3. **前后同一个人**：远景（代码人）和特写（MJ 图）不是同一个人。正式做时，特写的前后两张用第 3 节的 MJ 编辑出，远景的人物也从同一张特写的设定派生。
4. **MJ「动画图像」没评估**：有自动 / 循环 / 手动三种，5.2 s。浏览器截屏抓不到视频画面，要下载后逐帧看：像素网格会不会被糊掉、能不能过 `plates` 重新量化、会不会闪。
5. **像素颗粒指标对这类画面不可靠**：`look_report` 测出 13–19 px，但网格实际是 6 px（320 → 1920）。抖动纹理让自相关取到了倍频，这个数先不看。

## 8. s500 对照测试（2026-11-13，`测试/MJ探索_风格化/`）

同一内容出 6 组 24 张：便利店全景、地铁反应特写 × {普通提示词 s500，强像素措辞 s500，强像素措辞 s300}。全部过 `plates`（320×180，48 色）再比较。

| | 原图饱和度 | 像素版饱和度 | 像素版亮度（旧调色 → 新调色） |
|---|---|---|---|
| 便利店 普通 s500 | 0.46 | 0.37 | 0.14 → 0.26 |
| 便利店 强像素 s500 | 0.44 | 0.37 | 0.14 → 0.26 |
| 地铁 普通 s500 | 0.52 | 0.44 | 0.13 → 0.25 |
| 地铁 强像素 s500 | 0.48 | 0.41 | 0.12 → 0.22 |

结论：
1. **s500 缩成像素后质感留得住**：光、材质、景深层次都在，特写里的表情在 320×180 上仍然看得清（`细节_x6.png`）。s500 定为默认。
2. **s300 和 s500 差别不大**，s500 的光和细节略丰富。不需要往低调。
3. **「强像素措辞」会伤光影，不要用**（用户看出来的，2026-11-13）。`hard pixel edges, limited 32-color palette, big clean shapes` 让 MJ 用少数几级平涂来画光，变成赛璐珞式的两三阶明暗；`--no` 里的 `soft gradients, blur, bokeh` 又正好禁掉了光好看的来源：衰减、辉光、雾气、虚化光斑。之后 `plates` 再量化一次，等于砍了两刀。整体指标（柔和过渡面积、光晕强度）没有一致下降，差别在光的「层次」上，数字量不出来，以眼睛为准。
   **做法**：MJ 只管把光画好看，像素化全部交给 `plates`。提示词里不堆像素词，`--no` 里不写 `blur, bokeh, soft gradients`。
4. 低饱和措辞在 s500 下也有效：原图饱和度 0.44–0.52，比 s50 时（0.58）还低。
5. **旧调色太暗**（亮度 0.11–0.14，参考片 0.24–0.29）。新调色：饱和度 ×0.7、gamma 0.72（提亮暗部）、对比 1.06 → 亮度 0.22–0.26，饱和度在 0.37–0.44 之间。

## 9. 光影词对照（2026-11-13，`测试/MJ探索_风格化/光影对照_A.png`、`光影对照_B.png`）

在普通提示词（s500）上加两组光影词，各出便利店全景和地铁特写，全部过 `plates` 加新调色后比较：

- **光影词 1**：`volumetric light, warm rim light on <部位>, soft atmospheric haze, <光源> light falling off gently into shadow, bounce light on <表面>`
- **光影词 2**：`dramatic cinematic lighting, <暖光源> against <冷环境>, light spill and glow, deep soft shadows`

| | 全景（便利店） | 特写（反应脸） |
|---|---|---|
| 普通 | 光源多，但光比较平 | 脸清楚，光一般 |
| 光影词 1 | 有灯下的光锥、雨被照亮、窗外的光斑，**空气感最好** | 雾把脸的对比压低，**表情变弱**；人物还从男生漂成了偏女性 |
| 光影词 2 | 冷暖对比强，人物的轮廓清楚 | **最好**：脸受光明确，震惊的表情在 320×180 上一眼看得出来 |

结论：
1. 光影词有用，缩成像素后光的层次留得住。**默认加光影词 2**（冷暖对比加光晕）。
2. **建立镜头 / 空镜**想要空气感时，可以加光影词 1 的 `volumetric light, soft atmospheric haze`；**反应特写不要加雾**，雾会吃掉表情。
3. 光影词会让人物漂移（性别、发型）。人物描述里要写死性别和发型，例如 `a young man with short curly dark hair`。
4. MJ 偶尔会自己加上下黑边（电影遮幅）。`--no` 里加 `letterbox, black bars`。

## 10. 风格化按「在画面里有多大、要不要动」来定（2026-11-13，用户提出，初步）

| 素材 | 风格化 | 原因 |
|---|---|---|
| 场景、空镜、建立镜头 | **s500** | 要光影和空气感；像素化交给 `plates` |
| 大脸反应特写、表情卡 | **s500** | 质感和情绪；只做状态切换，不需要拆开动 |
| 场景里的小人（要走、坐、做动作） | **s100–200** | 描边干净、色块平，缩到 40–50 px 不糊；低风格化更听提示词（姿势清单、朝向、排版） |
| 小道具（屏幕上很小、要换状态） | **s100–200** | 同上 |
| 道具特写（画面主体） | s500 | 当成特写处理 |
| UI 图标、框 | s100–200（能代码画的优先代码画） | 形状要平、要规整 |

依据：同一个上班族，s100 的动作图像素最硬、描边最清楚、几个姿势最统一（`测试/MJ探索_小人加场景/chibi_overview.png` 第 3 行）；s500 更柔和，但会自己加柜台、朝向也不听。s200 还没测；低风格化小人放进高风格化场景里搭不搭，要等场景测试。
