# 画面分类与做法

> 2026-11-13，用户提出：视频里的画面可以分类处理，有的靠叠特效，有的靠 MJ 出多个状态。这页把每类画面的做法定下来。
> 依据是理发店样片 v1–v3（`测试/MJ探索_理发店/`）。v1/v2 是「MJ 底图 + 代码画人」，用户评价「没质感、太怪」；v3 是「MJ 画整个镜头 + 编辑出状态 + 代码只做切换、特效、声音」，方向对了。
> 和 [信息呈现手法库.md](信息呈现手法库.md) 的关系：手法库按**信息类型**分（数字、概念、对比……）；这一页按**制作方式**分。写分镜时先用手法库选「讲什么」，再用这一页选「怎么做」。

## 总原则

1. **人和景由 MJ 一次画在同一张图里。** 用代码画小人贴到 MJ 图上，细节密度和光对不上，一眼就是拼的（v1/v2 的主要问题）。
2. **代码不重画 MJ 的东西，只做四件事：** 在状态之间切换、叠特效、做镜头运动、出声音。
3. **每个关键词要有一个看得见、听得见的变化**：画面变化和音效一起落在字上。光有渐变（慢推、光线渐变）不算事件。
4. **网格**：世界 320×180（×6 到 1080p）；特效和 UI 在 480×270（×4）；字幕画在屏幕层，不跟镜头推，也不进调色。

## 一只索尔的「动」是怎么分配的（实测，2026-11-13）

按 10 秒一段统计每帧有多少像素在变（数据：`参考视频/拆解数据/动态分布.json`）：

| | 完全静止的帧 | 局部在动 | 大面积在动 | 切镜 |
|---|---|---|---|---|
| 《金钱心理学》298 s | **65 %** | 18 % | 15 % | 177 次（约 1.7 s 一切） |
| 《乌合之众》334 s | **50 %** | 26 % | 22 % | 199 次（约 1.7 s 一切） |

- **大部分时间是静止画面**，靠约 1.7 s 一次的切镜，加上 UI 和字的变化，让人感觉不到它是静止的。
- **大动态集中在少数几段**：开场前 10–30 s；一段高潮（《乌合之众》130–160 s 的人群段，大面积动占 51–55 %；《金钱心理学》90–100 s 的街景）；再加上零星几个有趣的点。
- 大动态段是真的动画：人群走动、街上行人和车、角色转身。静态段是细节很足的单张图（特写、道具、UI 选择框），停留时间都很短。

## 为什么大部分是静态，看起来却很流畅（六期实测，`参考视频/拆解数据/流畅度分析.json`）

| | 人类简史 | 富爸爸 | 深度工作 | 滚雪球 | 金钱心理学 | 乌合之众 | 我们 v3 |
|---|---|---|---|---|---|---|---|
| 每分钟切镜 | 16.6 | 9.3 | 26.8 | 12.1 | 32.2 | 21.8 | 19.1 |
| 冻住的帧 | 45 % | 46 % | 25 % | 39 % | 65 % | 45 % | **0 %** |
| 只有缓推 / 微动的帧 | 7 % | 7 % | 5 % | 8 % | 2 % | 6 % | 20 % |
| 镜头里面没有任何新东西的镜头 | 7 % | 6 % | 3 % | 0 % | 7 % | 2 % | |
| └ 这种镜头停多久（中位） | 0.3 s | 0.7 s | 0.2 s | — | 0.7 s | 0.3 s | |
| 镜头内新出现的东西 / 秒 | 5.3 | 6.7 | 5.1 | 6.9 | 6.1 | 5.1 | **2.1** |
| 切点落在旁白停顿 ±0.25 s | 52 % | 49 % | 41 % | 39 % | 46 % | 59 % | |
| └ 随机切的基线 | 20 % | 25 % | 25 % | 29 % | 34 % | 33 % | |

结论：
1. **「静态」不是 PPT。** PPT 是一页停住、慢推、再翻页。一只索尔的帧是**定住**的，但镜头里每秒有 5–7 个新东西出现：字、柱子长一根、标签弹出、换表情、眨眼。93–100 % 的镜头里有东西在出现；什么都不变的镜头只占 0–7 %，而且只停 0.2–0.7 s，是当节拍用的。
2. **变化是离散的、踩点的**：像素动画用低帧率，两次变化之间的帧完全不动，所以「冻住的帧」很多。我们 v3 恰好相反：颗粒每帧跳、镜头一直慢推，没有一帧是定住的，新东西却只有它的三分之一。连续的小抖动看起来像「一张图在被播放」，离散的变化看起来像「画面在讲话」。
3. **切点踩在旁白的停顿上**：39–59 % 的切点落在停顿附近，是随机切的 1.6–2.6 倍。
4. **同一个东西跨镜头带着新状态回来**：《金钱心理学》148–158 s 那段，一张柱状图跟着「20 岁、40 岁、50 岁、65 岁」逐根长出来；中间插三次主角的反应特写（震惊、闭嘴、斜眼，都是静止图）；再切回同一张图，它带着「11 岁」「你 −30 %」的新信息回来。观众始终在看同一个「东西」被讲下去，而不是一页页翻新图。
5. **信息镜头和反应镜头交替**：反应特写是成本最低、效果最好的「静态」画面，MJ 出一个人的 3–4 个表情就够反复用。

## 七类画面

| 类 | 什么时候用 | MJ 负责 | 代码负责 | 声音 |
|---|---|---|---|---|
| **A 建立镜头** | 新地点第一次出现（配音里点名的地方） | 连人带景的全景（第 2 节写法），人物在做一件事 | 缓推 ≤ 1.05；窗光里的浮尘、灯闪、天气粒子（pfx `weather/*`）；对话气泡 | 环境底噪 + 地点的标志声（理发店：剪刀、转灯电机） |
| **B 状态变化 / 时间流逝** | 「二十分钟后」「三个月后」「剪完了」 | 同一张图用**快速编辑**出 2–3 个状态（发型、光、地上的东西） | 状态之间一拍二（12 fps）闪切，变化概率从 0 爬到 1；曝光跳动；钟盘特效（`status/slowed`） | 越来越快的滴答、一串动作声、whoosh 收尾、「叮」落定 |
| **C 反应 / 笑点特写** | 情绪转折、包袱落地 | 特写，用快速编辑出「前」和「后」两个表情 | 切入时回拉 1.12 → 1.0 + 震屏；冲击帧（`impacts/impact-frame`）；头顶符号（`ui/exclamation`、`status/confused`、`status/stunned`） | 唱片刮擦、闷响；**切入那一刻把底噪全部收掉**，静默本身就是笑点 |
| **D 手和动作** | 第一人称的手做事（写、按、拿、递） | 手 + 道具，快速编辑出 2–4 个关键姿势 | 关键姿势一拍二切换，加 1–2 px 的位移和停顿；道具上的小特效（闪光、碎屑） | 拟音：素材库录音优先，没有就用 `synth` 合成 |
| **E 说明 / 抽象概念** | 道理、机制、对比（005 的双气泡） | 一张压暗的场景当背景，或者不用 MJ | 代码画 UI 装置（气泡、框、箭头），按字弹出 | UI 音：弹出、勾选、错误 |
| **F 金句** | 全片 ★ 句 | 不用，或一张极简的背景 | 大字、留白，镜头不动 | 一个 stinger，前后留静默 |
| **G 转场** | 段落之间、地点之间 | — | pfx `transitions/*`（iris、pixel-dissolve、crt-off）或硬切 | whoosh / 硬切无声 |

## 叠特效的做法（v3 验证过的）

- **冲击帧** `impacts/impact-frame`：320×180，正好盖满世界画布，0.33 s。用在笑点或反转的那一下，一集不超过 2–3 次。
- **头顶符号** `ui/exclamation`（84×104）、`status/slowed`（64×76）：太大，放在 480×270 的 UI 层上，不放在 320×180 的世界里。
- **对话气泡**：代码画在世界网格上（`zh10` 字、深色描边、尾巴指向说话的人），出现时 3 帧过冲（−3, −1, +1 px）。
- **镜头冲击**：`F.shake(t, t_hit, amp=12, dur=0.25)` 配回拉。
- **声音**：特效必须配音效，没有音效的特效是哑的（v2 的问题）。

## 已知的坑

- **MJ 编辑不懂镜子**：后脑勺剪短了，镜子里的头发还是长的。要再编辑一轮专门改倒影，结果仍然不完全一致。涉及倒影的镜头，尽量只出一边（只拍镜子，或只拍背影）。
- **分开生成的两张图，配角会变**：远景的理发师是黑发，特写里是白发。正式做时，同一场戏的远景和特写要从同一张图出发：先出特写，用编辑把人物保留下来；或者在提示词里把配角写得非常具体（发型、发色、衣服）。
- **事件密度不够**：v3 只有 25.5 次/分钟（标准 ≥ 55）。笑点特写停了 3.9 s 才有下一个变化，超过了 2.5 s 的上限。每 1–2 秒要有一个落在字上的变化。
