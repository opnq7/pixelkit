# STYLE GUIDE · 像素故事视频标准

标准 = 参考片《Claude Dreaming》（HD-2D：低分辨率像素美术 + 高质量光照 / 景深 / 调色）。每个镜头交付前按本页验收。

## 1. 画面量化目标（`pixelkit.qa.REF_TARGETS`，在参考片 1080p 室内帧上测得）

| 指标 | 范围 | 含义 / 不达标时怎么调 |
|---|---|---|
| sat | 115–155 | HSV 饱和度均值。低 → `GRADES.sat / vib` 或材质色板加饱和 |
| L2 | 3–20 | 最暗 2% 亮度：必须有真正的深色（阴影、轮廓线） |
| L50 | 80–105 | 中位亮度：整体比直觉更暗，靠光斑提亮而不是整体提亮 |
| L98 | 214–254 | 最亮 2%：必须有接近白的高光（阳光条、屏幕、bloom） |
| colorful | 52–82 | Hasler 色彩丰富度 |
| hi_b | 10–28 | 高光偏暖（黄） |
| lo_a | 10–17 | 阴影偏品红 / 紫（`palette` 的阴影色相 290°） |
| localC | 16–27 | 32px 块内亮度标准差 = 材质质感 / 微对比。低 → 材质噪声、百叶窗光条、道具密度 |
| lightVar | 30–52 | 大尺度明暗变化 = 光池对比。低 → 加强窗光、压暗角落 |

近景（大面积角色）允许 localC / lightVar 偏低；全景必须 ≥ 7/9 项在范围内。

## 2. 像素规则

- 世界美术分辨率 **480×270**；镜头缩放 1.0×–3.4×，`camera.warp_crisp` 保证像素边缘锐利。
- **一像素颗粒规则**：UI 画在 480×270 UI 画布上，整倍 ×4 到 1080p；字体只用像素字体 `zh12 / zh10 / zh8 / silk / p2p`。
- 轮廓线用深暖色（`ui.OUTL #2a1715`），不用纯黑；色板用 `palette.ramp()`（暗部色相往紫偏、亮部往暖黄偏）。
- 材质必须有纹理（`materials`：plaster / carpet_tiles / planks / ceiling_tiles / fabric / brick），禁止大面积纯色。

## 3. 光与调色

- 时段预设 `light.TOD`：`golden`（默认，粉桃色阳光 + 淡紫环境光）、`late`、`sunset`、`dusk`、`night`。
- 每个室内镜头的光层次：窗 → 百叶窗光条 → god rays（`rays` 1.0–2.0）→ 尘埃（`DustField`，n≈1000）→ 点光（显示器青光、状态灯）。
- 调色 `post.GRADES['golden_hd2d']`（夜景 `night_hd2d`）：bloom thr 0.70 / strength 0.55，暗角 0.34，颗粒 0.016。
- 「开灯」类转场：环境光与阳光分开淡入（例：amb 1.6→2.8 s、sun 1.9→3.0 s），比整体淡入更有层次。

## 4. 镜头语言

- 景别：近景 3.2–3.4×（表情）→ 中景 2.3×（角色 + 道具）→ 全景 1.0×（世界 + HUD）。缩放轨道用 `Track(..., log=True)` + `io` 缓动。
- 冲击用 `anim.shake`：小事件 2–3 px / 0.12 s，砸头 9 px / 0.3 s，爆发 18 px / 0.55 s；高潮前加持续轻颤。
- 冲击瞬间可加 3% 的推镜（punch-in），0.09 s 内完成。

## 5. 角色表演（Claude）

- **造型比例（v2，按参考片修正，用户反馈「v1 偏细长」）**：大头短身 Q 版。头 44×32（宽高比 ≈1.4，3/4 侧视：左侧露出 9px 侧面 + 珊瑚色耳盖），头占全身高度 ≈60%；躯干 24×15 + 短腿小脚；头宽 ≈ 躯干宽 1.8 倍；手是大圆白球（8×7），胳膊粗短。
- 屏幕脸占正面大部分；眼睛是竖椭圆（奶油色，下 1/3 桃色，外圈 1px 暗暖色光晕）；天线是金色细杆 + 发光小灯泡（不是十字）。
- 坐在桌后：头顶锚点 y = 桌面 − 44（躯干露出约 12px，腿藏在桌后）。旧版细长造型保留在 `characters/claude_v1.py`。

- 表情：`closed`（睡）→ `half` → `wide`（惊醒）→ `happy`（好的！）/ `focus`（工作）/ `dizzy`（被砸）/ `blink`。
- 每个反应都带身体：跳起用 `hop`，落地用 `squash_curve`（底边固定），被砸 squash 0.30。
- 视线：东西落在旁边时 0.05–0.32 s 内瞥一眼（`look=(2,0)`）。
- 状态灯 `led_k` 呼吸周期 2 s（睡眠），醒来常亮；打字节奏跟随剧情加速（9 → 18 次/秒）。

### 5c. 表演层（v0.7，第四幕 v2：与专业像素短片对比后的结论——差距不在画，在「演」）

- **画面里没有绝对静止的角色**：停留时也要有呼吸（`breath_px`，1px、呼气停留）、眨眼（`blink_face` 带中间帧）、每 2–3 s 一次 1px 视线变化。
- **每个动作 = 预备 → 动作 → 过冲 → 回稳**：预备是 2–4 帧的反向小动作（坐下前先往下蹲 squash 0.10），动作用缓动，到位带 ~6% 过冲（`PoseTrack(..., 'back')`），落地 `squash_curve`（0.12 左右，绕坐点挤压 `squash_about`）。
- **次级动作滞后主动作 2–4 帧**：天线 = 头部轨迹的弹簧滞后（`lag(head_pos)`，freq≈3.2 Hz，zeta≈0.22）+ 事件摆动（落地、灵光一闪）；头的歪斜跟着视线晚 0.12 s（眼睛先动，头再转，最后身体）。
- **一拍二**：角色姿势用 `on_twos(t)`（15 张/秒），水面 / 光 / 粒子保持 30 帧——像素动画的手感来自这个对比。
- **眼睛会跳不会飘**：`glance` 视线 0.09 s 内跳到位 + 小过冲，停留时完全不动。
- **一个节拍只演一件事**：坐下（squash + 脚掌踢起 + 天线晃）→ 闲不住（手指敲膝、脚交替晃、左看右看、两个加载点亮了又灭）→ 视线落到水桶（眼先到、头歪 6°、sparkle + 天线弹一下 + 灯泡变亮 → 星星眼 + 身体前倾）。
- **人类转头不超过 90°**：`person.head_dir(v)`，3/4 → 正脸 → 另一侧 3/4，0.3 s 内 3 张；头和身体夹角 >90°（例：身体朝 Claude、头转成朝水的侧脸）会像猫头鹰，**诡异**——要看另一边就让身体朝那边。老人默认身体朝水/鱼竿（钓鱼的自然姿势），和 Claude 说话时只转头；递东西、拍木板这类朝 Claude 的动作才把身体转过来。纯侧脸（1.6）在 Q 版大头上辨识度差，少用。
- **背景虚化必须仍是像素**：近景 / 双人镜头用 `pixel_soft`（网格 = 一个世界像素的大小），不用照片式高斯；光斑也是方块。
- **氛围粒子用原生像素**：蚊群放在较暗的远岸前，萤火虫在蓝调时刻；落地物体要有 1px 接触阴影。
- **光要落在角色身上**：双人镜头加地面反光 `bounce_light`（白天暖橙、黄昏偏紫），人和凳子都要 `contact_shadow`；灯笼用 `flicker` 轻微闪。否则人物像贴在背景上。
- **转头要有中间张**：`turn_track` 在两个朝向之间自动插 0 / 0.6；头与身体差 ≤ 2 单位（≈90°）。
- **脸屏可以「说」数字**：Claude 在心算时脸上直接显示算式（`face='txt:40×52/=2080'`），停一拍后变暗——比对白框更直接。
- **远处鱼跳涟漪画进背景**（在 `pixel_soft` 之前画），之后一起虚化；清晰的细环叠在虚化背景上，看起来像坏点 / 垃圾像素。
- **反应镜头**：对方说出「好笑」的话时，切 1–2 s 的听者近景（老人憋笑、肩膀 1px 抖动 `laugh_shake`），比一直拍说话的人好看。
- **对白框不能跨切点弹出**：框的展开动画从 `t_open − 0.16` 开始，所以 `t_open ≥ 切点 + 0.16`（`anim.boxes_cut_lint` 自动检查）；否则上一个镜头最后一帧会冒出半个空框。
- **重击要有物理反馈**：卡片被弹碎时画面震 2–3 帧（`shake_side2`），被吓到的角色往后缩 2px。

## 5b. 人类角色（来自 ACT II 王工，`characters/human.py`）

- 与 Claude 同一套 Q 版比例：头 30×27（超椭圆 n≈2.35）、躯干 22×15，头占全身 ≈55%；坐在桌后只露胸口以上。
- 一个人物 = 3–4 个强识别特征（王工：乱发 + 方框眼镜反光 + 胡茬黑眼圈 + 灰卫衣），其余保持简洁；配色比 Claude 更灰，让主角仍是画面最亮的暖色。
- 眼镜反光（`glint`）是「人物在思考 / 被屏幕照亮」的主要表演手段；表情变化要慢（tired → surprised 0.38 s → soft 微笑），对比 Claude 的弹跳式反应。
- 登场必配 `name_card`（名字 + 职位 + 一句笑点副标题），停留 ≈2.5 s。

## 6. 节奏（来自 v1 反馈：开头 10 秒不够抓人）

- **3 秒内必须出现第一个事件**（钩子）；之前只做氛围铺垫（黑屏呼吸灯 + 打鼾 + 钟表声 + 开灯）。
- 之后每 0.5–1 拍至少一个可见变化（新消息、砖块落下、表情、镜头变化），并逐步升级：单个 → 叠加 → 意外（砸头）→ 雨。
- 喜剧结构：**铺垫 → 加速 → 冻结 0.5 s（只有主角是活的，一个小动作）→ 爆发**。
- 所有关键事件落在音乐网格上（`Grid(bpm, t0=第一个关键事件)`），画面事件 = 节拍。

## 6b. 多镜头剪辑（来自 ACT I）

- 一幕 = 若干 Shot 类 + 一个剪辑表：`[(t0, shot, transition)]`，转场只用三种：**硬切**（喜剧节奏、冲击后）、**白闪 0.3 s**（时间跳跃）、**溶解 0.8 s**（情绪转换 / 入夜）。
- 每个镜头必须能单独渲染（`make(only=['sunset'])`）；镜头内部时间仍用全局 t，保证与音频对齐。
- 时间流逝 = 光线插值（`lerp_tod golden→sunset`）+ HUD 时钟快进 + ▶▶ 角标 + 加速消息流，三者同时出现观众才读得懂。
- 插入特写（挂钟）≤ 1.6 s，带 1.3→1.0 缩放落定 + 每声 tock 的小震动。
- 信息型窗口（词典、日历）：窗口开 → 打字 / 光标 → 结果 → 红笔圈重点，背景 `dim_blur` 压暗模糊，让视线只在窗口里。
- 积累型笑点（盖章）：先慢后快（单个 → 级联 → 翻页连盖），配计数器（工作日 N/365），最后白闪 + 巨章（倾斜 −12°、加粗）收尾。
- **中文印章要可读**：巨章只用于「砸」的冲击感；需要读出字的章（批准 / 已批准）角度 ≤5°、不加粗、`zh10 scale 3`，放在表单空白处，不压住关键字段。
- 表单 / 窗口类剧情（ACT II）：每个字段 = 一个小笑点（数字溢出 → 报错、悬停 tooltip 逐个否定、勾「其他」）；表单要够宽，最长的一行先排版再定窗口尺寸。
- 两条线交叉剪辑（Claude 提交 ↔ 王工审批）：先单人近景建立人物 → 特写反应 → 双人全景交代空间关系 → 回到操作。

## 6c. 外景 / 多场景（来自 ACT III）

- **站位先避开前景遮挡**：前景路灯、树干会整根挡住角色（第三幕「失败」镜头原站位 x≈212 正好在路灯后，改到 182）。每个站位在静帧里用最终镜头缩放检查一次。
- 地图 / 航拍镜头里的小人要放大 2 倍（`claude_mini` ×2），否则 1080p 下只剩几个像素，观众找不到主角。
- 气泡、问号、对白的锚点用**头顶位置**（随姿势 / 坐下变化），不要用精灵框顶边。
- 群像镜头（「四个人类的周末」）：每个小故事 1 个动作 + 1 句话，镜头之间用暖色递进（`WARM` 逐镜升高），情绪从「Claude 不懂」走向「Claude 看懂了」。
- 音乐动机呼应：Claude「高效地休息」时回归第一幕的**工作主题（Theme A 芯片版）**——观众会听出「它又在工作了」；真正放松的段落只用 Theme B。
- 喜剧爆点（全城自动回复「啊——？！」）：大字用暗色衬条托底 + 画面抖动，之后**定格**（降饱和 + 慢推 + 只留风声）给观众笑的时间。
- 结尾留白：钢琴独奏，停在未解决的和弦上，把问题留给下一幕。
- **台词要读得完**：每句完整显示 ≥ max(1.0 s, 0.1 s/字)（`boxes_lint` 自动检查）；气泡寿命用 `read_time`。v1 的问句因为下一句太早把框切掉，完整显示只有 0.1 s。
- **转场要有动机**：从一个场景跳到「地图 / 屏幕 / 回忆」时，让它从角色身上长出来（脸屏变地图 → 镜头推到脸上 → 地图从屏幕放大铺满；回来时再缩回脸里）。
- **因果先行**：群像小故事里，每个人先给「原因」（暗色自动回复弹出 → 放下手机）再给「结果」（被风筝 / 朋友 / 阳光吸引），否则观众只看到一堆人在发呆。
- **情绪高潮要露出内容**：「说几句真心话」不能只停在台词上，用暖色回忆气泡把内容演出来（`ThoughtBubble` + 怀旧调：暖偏色、抬黑、暗角、轻颗粒）。
- **任务结构**：主线任务贯穿多幕（「学会休息」留到第四幕完成），每次尝试是一个支线（弹出 → 失败打 ✗ → 下一个支线），观众能数清这是第几次尝试。
- **大事件后留余波**：定格之后加 2–3 s 过渡（气泡逐个消失、鸟飞过、颜色恢复），再进入下一段情绪。

## 6d. 像素 → 油画（全片只破一次画风，来自油画转场小样）

- 含义：**像素 = 被计数的时间，油画 = 没被计数的时间**。油画里没有 UI、没有数字；只有 Claude 的「— —」脸和旁白框保留。
- 动机：转场必须由角色动作触发（Claude 拨「消息提醒：关」→ 鱼漂一晃 → 涟漪从鱼漂扩散，涟漪扫过处化开成笔触）。
- **不要套滤镜**：笔触几何固定（`Painter` 一次生成），每帧只更新颜色——否则画面会「爬」和闪。试过的失败方案：胶囊状圆头笔触（像药片）、LIC 流线（像指纹）。
- 三段式：像素 → 化开（`soften`，前沿 46 px 宽的软带）→ 油画；前沿逐块（2 px 方块 + Bayer 抖动）翻转，不要软擦除。
- 人物 / 太阳是焦点区：小笔触 + 混入 50% 柔化源图，且焦点区去掉鬃毛纹理和厚涂（否则头上出现同心纹）。
- 鱼漂全程保持像素（推镜时用最近邻缩放），收尾画面里**只有它是像素**——它是这一段的「锚」。
- 推镜要定点（`zoom_matrix` 保持焦点不动）；原稿的「拉远」在单张画面上做不到，改为 1.00 → 1.05 缓慢推近。
- 声音同步化开：涟漪前有 UI 电子音，涟漪后不再出现电子音；混响随涟漪进度从干到湿（rt 3.2 s），环境声降 60%，钢琴旋律进来，第一颗星用两个八音盒音。
- **v2 定格**：油画全屏后旁白读完就收框，再留 ≥4 s 无 UI 纯画面；定格时保持微动（光变 / 慢推 / 鸟群 / 第一颗星在定格中段），音乐停掉分解和弦，只留长音。
- 定格画面要经得起看：构图用「海报」思路（引导线：栈桥透视指向太阳；人物在三分线；鱼竿伸向光柱、不穿过别人）；天空笔触低抖动长笔触，小东西（道具 / 小镇 / 芦苇）走细笔清晰层，否则全被抹成粉色糊。

## 6e. 幕间转场

- 不用章节条；用角落时钟 HUD 交代时间跳跃（时钟 = 被计数的时间；油画段没有时钟）。
- 优先「物件 / 光 / 方向」匹配：安全出口灯（二→三）、走向方向一致（三→四 从左往右）、鱼漂匹配剪辑（四→五）、彩蛋复用第四幕构图。
- 声音桥：下一场环境声提前 0.5–1 s 进；情绪转折处用硬切（水声 → 滴答）。

## 6f. 对白场景 / 近景（来自 ACT IV）

- 节奏最慢的一幕：单镜头 4–8 s，对白之间留白；双人背影中景交代关系，再切正反打近景。
- 近景：背景 `dof()` 虚化（sigma 13–15，高光变光斑），人物锐利；逆光时把边缘光 `bake_rim()` 烘焙进精灵；镜头 4–4.5×，人物用最近邻放大，保持像素边。
- 透视纵深走位：机位≈人物高度时，人物头顶一直在地平线附近——**不能从画面下边升入**，要从侧边大尺寸入画再拐上栈桥；速度按 1/s 线性（世界速度恒定）。
- 两个声线：Claude 音节 blip（tri，shift −5，10–12 字/秒）；老人更低更慢（shift −14，d 0.085，6–8 字/秒）。对白框带名牌 + 头像，老人头像说话时嘴巴开合。
- 「效率」被拒绝要有物理结果：数据卡随关键词逐行长出 → 一句「那多没意思」→ 卡片开裂、碎块落水；音乐在这句话上停在小节中间，留出空白再响碎裂声。
- 角色的「想通了」：加载圈先快后慢（14 → 4 点/秒），滴答声同步变慢变轻 → 「— —」 + 一个轻扫和弦（呼气）→ 才做动作（拨开关）。
- 手部特写：伸进画面的手臂精灵必须**一直延伸出画框**（否则像一截漂浮的木块）；手与 Claude 的手同一像素尺度。
- 拼接现成片段（油画段）：本幕音乐小节网格要对齐片段的第 0 小节（`T0 = 偏移 + 片段首小节 − k·BAR`），片段自带的 UI 声关掉，整体压低约 5 dB 再进总母带。

## 6g. 桌面窗口 UI（v0.8，来自第五幕周报 + 第一幕回炉）

- 窗口是画面里最大的一块、停留 ≥5 s 的，必须做「应用」而不是「一个框」：标题栏图标 + 菜单栏 + 工具栏 / 搜索行 + 内容区 + 分段状态栏 + 柔和投影（`soft_shadow`）。全片统一 Win95 语言（`w95_*` 零件），不要混别的系统风格。
- 内容要有层级：标题（加粗 + 藏青分隔线）> 正文（zh10/zh12 墨色）> 元信息（zh8 灰）；列表用编号方块；文档类用「灰桌面 + 白纸 + 阴影」，不要白框贴满。
- 状态栏是讲故事的地方：`正在撰写… / 正在想… / 已自动保存 / 已发送给 …`、`休息日 0 天 · 下一个假期：未安排`。字数、进度跟着画面实时变。
- 交互要有完整状态：按钮 idle → hover（鼠标到达前 0.2 s）→ pressed（0.12–0.14 s）→ 结果（绿色 ✓）；鼠标落点放在按钮文字右下，不挡字。
- 流式生成：当前行末尾一个橙色块光标 + 最后 3 个字淡入；犹豫删除用选区从右往左扫（0.36 s）再整段消失。
- 排版先按最长一行和最终内容算高度（周报 P.S. 那行曾被裁掉）；窗口不要压到下方对白框的位置（UI y ≤ 232）。
- 小字 zh8 只用于菜单 / 状态栏 / 元信息；列表项、正文至少 zh10。

## 6h. 布景密度（v0.8）

- 同一间办公室所有幕都用 `Office.background(dressing=True)`：墙上书架 / 软木板 / 小画，地上绿植 / 档案箱 / 衣帽架 / 垃圾桶 / 纸团 / 地毯；桌上笔筒 + 显示器便签。参考帧的「生活感」主要来自这些小物件，不是来自光。
- 早晨：`tod='morning'` + `morning_hd2d` 调色 + 光柱 + 尘埃 + 杯子热气（`SteamWisps`）+ 窗台鸽子。

## 6j. 幕与幕的接法（v0.8.1）

- 每幕开头不用章节条；从黑场淡入到**上一幕最后一个镜头的同构图**，再用 1.5–2.5 s 推到本幕构图。时钟 HUD 滑入并翻一分钟（被计数的时间），配一声 tock；本幕的环境声（钟表滴答 / 夜晚底噪）从第 0 帧就有，拼接时可再提前 0.5 s。
- 大窗口出现前给角色一个「下定决心」的小动作（停手 → 天线一弹 → 双击），窗口从显示器里弹出，不凭空出现。
- 窗口不能盖住 HUD（时钟 / 计数器）和对白框（y 200 以下）：先量出可用区域再定 `*_R`。

## 6i. 情绪的克制（v0.8.1）

- 难过 = `sad` 眼 + **一滴**脸屏眼泪（`claude.draw(tear=k)`），台词说完后再掉，2 s 左右走完；不连哭、不加抽泣音效、不让动作停下（夜景里它还在打字）。眼泪用冷青色，和暖色眼睛拉开色相，小尺寸也读得出。

## 6k. 片尾 = 最后一场表演（v0.9，第五幕片尾 v2）

- 片尾不是滚动字幕，是**角色的最后一场戏**：黑盒舞台 + 一盏追光（`credits.Stage`），角色站在光里，字幕从它头顶升起。参考片像素段的质感来自「每一拍都有表情反应」——每出现一行字，角色都要对它有一个反应（看一眼、得意、装傻、偷看）。
- 字幕用**平滑衬线字 + 金色**（`credits.line / credit_row`），和像素角色形成对比；角色名用 Georgia 斜体（拉丁字），中文用思源宋体。每行 `pop` 升入、扫光一次；同屏 ≤ 8 行，行距 ≥ 1.25 倍字号。
- 自嘲式幽默的写法：①一个人包办所有职位，每个职位配一个 0.6 s 的小道具 / 动作 + 一枚金币（音高递增 = COMBO），节奏要稳定；②「数据卡」先摆一本正经的数字，最后一行反转（「周末 1 个（已使用）」「效率可提高 +83%」→ 它自己不屑地弹碎）——呼应正片的笑点；③免责声明后**留一拍安静**再耸肩；④真诚的一句（致谢）不开玩笑：鞠躬 + 爱心眼；⑤最后让角色「下班」（状态灯变灰、坐下、睡着），再用一声「叮」让它睁一只眼——把观众引到彩蛋。
- 匿名致谢：用描述代替名字（「一个相信它的人类」），比写名字更有温度。
- 道具跟头走：贝雷帽 / 铅笔 / 耳机的位置以头顶锚点（含 `head_dy`）计算；甩头时道具按抛物线飞出、淡出，别凭空消失。
- 声音：一盏旧灯的「咔哒 + 低嗡」开场；吉他慢和弦按「职位节奏」的小节走；每个小道具一个小音效（场记板 clack、跳 jump、天线 boing、剪辑 snip、渲染 ticks + 风扇 → 叮）；碎片落地用 `ui.shatter_hits` 排 plink。

## 6l. 片尾要暖，问题放进故事（v0.10，第五幕 v3）

- **不用纯黑片尾 / 黑屏字卡**：纯黑舞台太冷、像结束了。片尾放进一个暖色小剧场（`credits.Theatre`）：红丝绒幕布要**暗、低饱和、褶皱宽而少**（字幕区再压暗），台前灯从中间往外逐个亮（每对一声咔哒），木地板 + 金边台口。
- **前排观众 = 故事里的人**：背影剪影要大（`sc≈1.9`，头宽 ≈30 px），一眼认出是谁：草帽 = 老人，乱发 + 眼镜腿 = 王工，空座上一张「鱼」的预留卡。他们跟着 Claude 的笑点点头、鼓掌、跟着它一起打瞌睡，「叮」一声一起醒——观众席也是表演的一部分。座椅靠背挡在人前面，只露头肩；轮廓光只打在上沿和头两侧。
- **不要用黑屏问句收尾**：问题的答案放进剧情（周报发出后同事回「……好。」「这周末去。」、角色 ^ ^、台历上画圈的周六），旁白写**状态的变化**（「我以前没有周末。」→「现在，我知道它长什么样了。」），比直接问观众更有余味。
- 抽象概念要换成具体的物（「周末」砖块 → 台历上红圈 + 小鱼）；数据卡的反转行跟着剧情更新（「已用 1 个 · 已约 1 个」）。
- 片尾音乐 = 周末主题的白天版（`music.weekend_bright`）：职位一拍一个、落在拍点上；第 0 小节只有灯，第 1 小节贝斯 + 尤克里里进来，第 2 小节完整律动；免责声明处整个乐队停一拍；致谢 / 鞠躬回到柔和八音盒；角色坐下时最后一个和弦延音，然后只剩鼾声和「叮」。片尾里的小道具音（漂浮音符）也要在调内、在网格上。
- 混音：律动 / 旋律总线比片尾音效低约 3 dB（音效是笑点），片尾整体与正文段落 RMS 相差 ≤ 2 dB。

## 6m. 近景 = 放大世界像素（v0.11，彩蛋：一次走弯路的结论）

- **近景必须是把世界本身放大（3–4.5×，最近邻）**，和前五幕一致；不要为近景另画「高清」角色 / 道具。彩蛋 v2 试过原生大尺寸重画（`vec` / `closeup` / `cu_props` / `cushot`），用户一眼看出「画风完全变了很怪」→ 已撤回，这四个模块**不用于本片**。
- 近景粗糙的真正原因是光太平 + 普通高斯虚化，不是像素太大。解决：`World.render` 的 `st['bg_soft']`（`pixel_soft`，网格 = 一个世界像素）+ 近景专用补光（主光、对侧冷色轮廓光、屏幕闪光）+ 尘埃。**禁止平滑渐变 / 高斯虚化的近景背景。**
- 镜头内的小动作（手伸向相框）画成独立精灵放在道具前面（`human.reach_arm`），不要改整张桌子。
- 背影坐姿：圆肩、手臂收在身侧（带肘部折痕）、衣服下摆盖臀部、裤子坐在木板上 + 接触阴影；去掉孤立像素。转头用整头平移 2 px + 那侧耳朵收起 + 露出一点脸颊和鼻尖（`old_fisher_back(turn=)` / `wang_back(turn=)`）。
- 照片 → 现实的转场：~~硬切进照片同构图~~（v1，用户觉得怪，已改）→ 见 6n。
- 外景收尾的「时间在走」：太阳继续下沉几像素 + 光往紫色偏（`river_pier.DuskDrift`），加飞鸟、水面星芒、光尘，都很轻。

## 6n. 走进照片（v0.11.1，彩蛋 v2）

照片只占半个画面时**不要直接硬切**成满屏的照片世界：比例突然跳、照片里的人（小孩 + 年轻父亲）和切过去的人（王工 + 老人）也不一样，观众来不及读懂。顺序：
1. **推满**：相框特写末段加速推进（`anim.push_zoom`，零速落定），推到 `PhotoFrameInsert.fill_cam()`——照片高度 = 画面高度，木框 / 白边滑出画外（左右露一点白边没关系）。状态徽章等 UI 在推满前淡出。
2. **溶解进照片**（`Edit.add(..., 'dissolve', 0.7)`）：接同机位、`film_grade(k=1)` 的照片世界（照片里的人，`photo=True`）——同一张图，只是「雾散了、水开始动」。
3. **停一拍**（≈0.3 s）再**照片内匹配溶解**（≈1.1 s，同机位渲两遍世界交叉淡化）：照片里的人 → 现在的人；同时胶片颗粒 / 偏色 / 日期戳褪掉（≈1.0 s），镜头随后缓慢拉远。
4. 声音跟着画面：旧场景声随溶解淡出（不硬切）、新场景声同步升起；匹配溶解时一声很轻的 shimmer；和弦落在胶片褪掉的时候。
5. 推镜的中心用 `anim.screen_follow` 跟，避免甩。

## 6o. 全片拼接（v0.12）

- 接缝只有三种：**黑场**（0.6–1.0 s，上一幕已淡出、下一幕从黑淡入时）、**过场片段**（有时间跳跃时：黑场 HUD 翻时间 / 延时走路）、**无缝**（两幕是同一镜头：在上一幕淡出前切走，下一幕去掉淡入，从同一帧接着动）。
- 过场复用上一幕的布景和角色代码，不重画；只有主角真速，路人 / 光 / 时钟做延时。时钟 HUD 如果下一幕开头也有，就**一直带过切点**，不要先淡掉再淡入（会闪一下）。
- 声音：下一段的环境声预叠 0.5–1 s；黑场里的滴答对齐下一幕自己的节拍网格和音量（从成片里量）；无缝接时上一幕尾音（它自己的淡出）叠在下一幕开头。
- 过场单独 mix 到约 −20 LUFS（比正片安静）；预叠的环境声电平要对齐下一幕开头的实际电平（本片水声预叠第一次做成 −10 dB RMS，比第四幕开头高 10 dB，要先 `--audio-only` 看接缝 RMS）。
- 整片一个增益到 −16.5 LUFS，不再压缩；拼好后 `vqa --cuts` 查接缝，抽每个接缝前后各 1 帧看。

## 6p. 大像素 + 画出来的光（v0.13，《熬夜副本》与参考片对比后的标准）

- 美术分辨率 **320×180**（1 美术像素 = 1080p 的 6×6），舞台用 `pixstage.Stage`；UI 仍是 480×270 ×4，字幕单独一层 384×216 ×5（60 px 字高）。
- 一点透视房间，暗部接近纯黑，一个暖色主光 + 金色点缀；光用 `band`（硬边 2–4 圈色阶）/ `cone`（光柱）画出来，空气里的光走 `air=`。
- **布景密度**（开场 v1 被批「敷衍」后的结论）：每个镜头三层——前景压暗的轮廓（衣服椅、被角）、中景一个高对比主角物件、背景压暗压饱和的「讲故事杂物」。杂物要替角色说话：外卖盒、能量饮料金字塔、全是红叉的「早睡打卡」、扣在月光里的《早睡指南》、拉到绷直的充电线、床尾睡着的猫。
- 主角物件用 `Stage.part(mask, ramp, bevel, light)` 做体积（vec.Painter 的倒角 + 色阶 + Bayer 抖动），背景用平涂 + `dither`。
- 近景不要把 30 px 的小人放大：用 `vec.Painter` 原生画大号（`characters/face_cu.py`），参数全连续（lid / look / pupil / red / mouth / tilt / dy），直接接表演曲线。
- **钩子（前 2 秒）**：第一帧就在动（手机刷视频 POV），旁白 0.45 s 进；时间 / 任务这类信息做成游戏 HUD（玩家状态栏、任务追踪器、已刷计数），让信息本身有趣。
- **屏幕文字的停留**：任何面板里的字必须在切镜头前完整出现并停留 ≥ 1 s（timeline 里登记 `TEXT_EVENTS`，`check_text_holds()` 自检）。结算类信息不压旁白，单独给 3–4 s 静默读完时间（每行一个音效）。
- **梗交给画面，旁白只补一刀**：「至于这个选项……是装饰」这种把梗说破的句子改成画面先演（手伸向按钮、按钮发光诱惑）→ 旁白一句短的回扣（「别点了。你上次，就是点的它。」）→ 角色反应（僵住、冒汗、缩手、吹口哨、改点接受），音乐在旁白那一刻断掉。
- **数字要有意义**：不用观众不懂的梗数（1024）；用能让观众「被说中」的统计（本月第 23 次说"就十分钟"、手机电量 100% vs 你的电量 0%）。
- UI 在画面上方漂过角色时（任务面板 vs 小魂），把角色画进 UI 层（`ui.blit_scaled` ×3 ≈ 世界像素 ×2.85）。
- 叠加动画的 alpha 一律经过 `ui._a`（已夹紧 0..1）；`back_out` 有过冲，不要直接当 alpha 用。

## 6q. 表演与笑点（v0.13d，《熬夜副本》第 2–5 关）

- **每个房间 = 背景板 + 2–3 个会动的东西 + 1 个和主角的互动**（档案室：小工推车、卡片飞进抽屉、「尴尬记忆 · 永久保存」；情绪科：烘干机转着焦虑云 → 叮 → 叠好的毛巾；地下室：拉闸、闸门升起、浪把小魂冲走、湿漉漉冒出来发抖）。
- 角色表演一律走 `acting.Act`：时间线里只写 beat（take / startle / freeze / tumble / whistle …），不在镜头函数里手写抖动。
- **抽象概念 = 会演的角色或游戏机制**：睡眠债 = BOSS 血条（周末懒觉只打掉 -2）；PER / TIM = 两个蛋白小人手拉手去拉闸；「自我感觉 100% vs 实际 46%」+ 说「我挺好的」时点头微睡。
- **贯穿梗要升级**：「我还能再熬会儿」按钮每关换伪装（开场：伸手被叫停 → 第 2 关：门后探头 → 第 4 关：「周末补觉券」被盖「骗人」→ 结尾：商店里标价「睡眠 × ∞」，小魂自己推开盖「不要了」）。
- UI 文字避开字幕安全区（UI 画布 y > 215）；成就 toast 放顶部 y=44。
- 弹幕（`danmaku`）用来做「观众自我代入」的群体反应（「我」「+1」「六小时都算奢侈」），一句旁白配一屏弹幕。
- 背景板来自 GPT：先 `plates.Plate` 像素化，再在 `grid_*.png`（20 px 网格）上量锚点。

## 6r. 不闪、不叠、不怪（v0.13f，第 4 关 v3 → v4 的教训）

- **不频闪**：整屏亮暗每秒反向变化不超过 2 次（`python3 -m pixelkit.qa flicker out.mp4`，出片前必跑）。表现「时间流逝」用同机位重复 + 递进（第 1 / 7 / 14 晚），不用日夜快切。
- **顶部中间只放一个东西**：问题卡 / 横幅 / BOSS 条 / 答案卡排队用 `gameui.TopSlot` 自检。复活条只在存档点和选门出现。
- **画不好的就不画**：特写手、写实身体不画；需要的实物（反应盒、病床）让 GPT 出背景板，我们只叠会动的部分（数码管、按钮、道具）。睡着的人：床正对镜头 + Q 版正脸 + 背景自己的被子盖住下巴。
- **Q 版角色不放大成全屏**：特写最多到头肩，或带着场景。
- 抽象概念要有实物在演：闹钟 → 欠条罐 → 反应盒 → 打印纸 → 欠条怪。

## 7. 声音标准

- 母带：**−16.5 LUFS 整体响度，真峰 ≤ −1 dBTP**（`master.finalize`）；氛围段比主体低 14–18 dB 属正常。
- 混响发送：音乐 rt 1.2 s / 0.25，音效 0.7 s / 0.20，人声（blip）0.45 s / 0.15；冻结段完全干声。
- 冻结：冻结前所有总线（含混响尾巴）在冻结时刻**硬切**（`master.cut`），冻结后在新网格（`grid.shifted`）上重启。
- 角色「说话」用音节 blip（`voice_line` / `ok`），音高随和弦移调；大量重复时去掉 jingle、降低增益、随机移调。
- 密集事件（砖块雨）按局部密度降增益：`g = base / sqrt(max(1, n/2.5))`；声像按镜头换算（`pan = (x-cx)·zoom/240`）。
- 每个镜头换总线组（如 SM/SX/SV/SB），镜头切换处对上一组 `cut` 或 `fade`；插入特写只留房间底噪 + 张力 pad + tock，制造「静」。
- 情绪段落换主题：工作 = Theme A（明快），周末 / 想象 = Theme B（慵懒 + 八音盒），周末真的来了 / 片尾 = Theme B 白天版（`weekend_bright`），夜晚 = `night_bed` + 钢琴短句。
- 犹豫 / 等待：音乐抽空，只留张力 pad + 心跳（`heartbeat` 56→74 bpm）+ 远处消息提示；点击瞬间音乐硬停，留进度条滴答。
- 主题动机叙事：王工微笑时 Theme B 先以八音盒「预告」，盖章后 Theme B 全编制进入（周末要来了）；关机段只留一个持续和弦 + 开关声 + 八音盒尾音 → 静音。
- 配乐：Theme A 132 bpm，C–Am–F–G；段落按「低音 + 镲 → + 琶音 / 鼓 → 全编制 + 16 分音符跑动 + 军鼓滚奏 + 上升音效」递进。
- 呼应型声音（第五幕）：同一个提示音（叮 / 「好的！」+ 金币 / 状态翻转）在首尾两幕**完全一样**；第一幕主旋律放慢、只留贝斯 + 琶音当「工作模式」，角色停住时音乐断掉、只剩挂钟秒针；黑场问句全静。
- **安静段落不配乐**（第四幕 v2）：开场到「关」提醒之前只有水声、鸟叫、木板嘎吱和小表演音（憋笑 `chuckle`、叹气 `sigh`、天线 `boing`、脚跟敲木板、渔轮 `reel`），Claude 的不自在才明显；音乐在做出决定后才进来：拨「关」0.35 s 后一层暖 pad 淡入，带进油画段。
- 每个可见的小动作都配一个很轻的声音（-30 dB 左右）：跳上木板 = jump + 软落地 + 嘎吱；挪近 = 嘎吱 + 布料摩擦；脸屏数字 = digit_ticks；变暗 = 下滑正弦。

## 6s. 一关的骨架与「一次只聚焦一件事」（v0.13h，全片拼接）

1. **每关固定四拍**：问题卡（`question_card`，顶部中间）→ 附身 / 实验（一个场景一个比喻）→ 答案卡（同一槽位，`TopSlot` 自检不叠）→ 回到 03:56 冻结的卧室（`levelkit.Anchor`：复活 +N%，房间颜色逐关回来）→ 门厅（`HubDoors`，下一扇门亮）。结尾关把同一个存档点推到终点：颜色全回 → 时间重新走（`clock` 03:56 → 07:12 滚动）→ 窗外 `dawn`。
2. **商店 / 列表类画面**：镜头一次只聚焦一件道具（`keyed` 镜头路径推到物品，卡片在固定位置弹出，小魂缩小躲到角落不挡物品），最后拉远排成一排（`item_row`），所有价签翻成同一个字（「睡眠」）。道具图标直接从 GPT 底图裁 24×24（`Plate.rgb[y-12:y+12, x-12:x+12]`），不重画。
3. **梗要「大」**：按钮、空展柜这类笑点放进世界里（有体积、有光、被推走掉出画面），UI 只放价签 / 印章。
4. **整帧特效放后期**：`fx.melt`（幻觉）/ `fx.eyelids`（微睡眠，droop≤0.5 = 全闭；眨眼幅度 ≤0.26，别遮掉整个画面）。
5. **不画手**：「打脸」用 `啪！` 拟声 + 碎字 + `打脸` 印章，不画巨大的手。
6. **字号**：中文最小 zh10，`∞ −` 这类字体缺字（`core.missing_glyphs`）一律换 `无限` / ASCII `-`。
7. **文字不压人**：计数 / 标签放在左下（y≈186）而不是画面中心；说话用 `ui.speech_bubble` 而不是裸文字。
